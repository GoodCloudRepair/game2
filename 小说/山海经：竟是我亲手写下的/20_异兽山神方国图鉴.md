# 异兽山神方国图鉴

本表记录本书使用版本。参考《山海经》原型，正文以生态、古卷立场、行动冲突和文明交流为适配原则。

## 古卷立场代码

| 代码 | 立场 | 典型目的 |
| --- | --- | --- |
| D | 毁卷 | 杀执卷人或摧毁古卷，避免真形与天赋入经 |
| S | 夺卷 | 抢夺古卷，用于记录敌手、掌握弱点或争夺权力 |
| A | 避卷 | 隐形、迁徙、封闭领地，拒绝接触执卷人 |
| N | 议卷 | 谈判可写内容、经印归属和公开边界 |
| R | 求录 | 主动托付见闻或族志，让濒危传承留存 |
