# 异兽山神方国图鉴

## 使用规则

本图鉴统一以通行十八篇本《山海经》为原文依据。每个物种必须保存“原文摘录—原文效用—本书生态与战斗表现—限制”链路。

- 形貌、声音、食用或佩用效果不得擅自改成无来源主动神通。
- 生态、族群、领地和战法可以在不违背原文的前提下适配。
- 物种条目形成后不可删除；承印者与收录模式必须另行登记。
- 本表的神话位格用于作者判断存在层次，不是全民修炼境界。

## 古卷立场代码

| 代码 | 立场 | 典型目的 |
| --- | --- | --- |
| D | 毁卷 | 杀执卷人或摧毁母卷，阻止物种本源与弱点入经 |
| S | 夺卷 | 控制后续入册、掌握敌手弱点或成为新执卷人 |
| A | 避卷 | 隐藏真形、迁徙或封闭领地，拒绝产生承印者 |
| N | 议卷 | 谈判公开见闻、承印者人选和入册方式 |
| R | 求录 | 为气运、血脉延续或文明存档主动承担入册代价 |
