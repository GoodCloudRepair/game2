# 卷01 001-030章章纲

卷名：南山初卷·招摇至青丘

状态：按“开篇前七日已完成三项物录、第001章直接首兽开印”重排定稿，可作为后续写章依据。

卷目标：闻天问魂穿招摇山一具刚断气的无部流民身体，以凡身在万灵围猎中正面击败赤眉，完成狌狌首录并踏入承印境；随后卷入榖部夺卷与迁营冲突，沿堂庭、猿翼、杻阳、怪水、柢山、亶爰、基山抵达青丘，以鹿蜀、灌灌两次自愿入册补足第一卷印，最终形成《南山不息》。

卷一核心矛盾：闻天问需要通过入册获得活命与战斗资本；异兽与人族却都认为母卷可以被毁掉、夺走或利用。母卷客观不可抢夺，但杀死、囚禁和胁迫闻天问仍能阻止或控制后续落字。

卷一成长线：祝余、迷榖、育沛物录基础 → 第001章正面压服赤眉、首兽开印 → 狌狌强录后果与榖部控卷 → 鹿蜀与灌灌属性积累 → 第一卷印《南山不息》、承印境稳固。

卷一开篇前物录：祝余、迷榖、育沛。卷一正式异兽入册：狌狌、鹿蜀、灌灌。物录不产生承印者或卷印贡献；白猿、旋龟、鯥、猼訑、九尾狐只作文录、遭遇或议卷，不入册.

卷一禁止项：不写还印、释籍、经印清零；不写古卷自动镇压救场；不写循旧迹、模仿旧声、九尾狐天生幻术；不写实体母卷被抢、撕页或焚毁；不写系统任务、数值提示、黑雾、鬼影或诡异低语。

### 001-010阶段状态

- 时间：魂穿后的第七日至第十一日；开篇前六日经历只作既定前史。
- 闻天问：第001章由凡身踏入承印境初立；肩、胸有抓伤，首兽强化没有清空旧伤。
- 物录：祝余耐饥、迷榖辨路、育沛稳腑，均为轻微永久被动，不产生经影或卷印贡献。
- 异兽入册：狌狌永久入册，赤眉为强录承印者，双方保持敌意与战败承认。
- 能力：主动特殊能力只有狌狌“善走”；经影必须与闻天问动作同步。
- 关系：阿禾由戒备转为有限信任；岩从夺卷转向控制执卷人；榖部迁营队暂时同行。
- 地图：完成赤泉、榖部猎营、招摇南麓与南口闭环，进入堂庭。
