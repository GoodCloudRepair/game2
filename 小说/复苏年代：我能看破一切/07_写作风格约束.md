# 写作风格约束（起点 · 都市高武）

## 定位

起点男频老白向：逻辑自洽、收益可见、布局有兑现；都市底色不丢（手机、短视频、高考、通勤）。

执行最严苛审稿口径：具体标准见 `24_严苛审稿门槛.md`。本书宁可重写，不保留逻辑弱、人物假、收益虚的段落。

## 文风

- 冷静、干脆，少煽情排比
- 危机写现实压力、动作判断和代价，再写可见收益；不以悬疑氛围替代高武行动
- 打脸靠实力自然露出，不刻意装逼演讲
- 设定穿插剧情释放，禁止半章说明书
- **危急时写动作与体感，不写"本能/脑子里只剩/不是A是B"解说腔**
- **禁止给妖兽读心（如"猎物不该…"）；旁观动机少解释，动作即可**
- **目标用检索、收藏、花钱算账兑现，禁止"短期目标钉死/长期目标"提纲句**
- **洞察写成可操作判断：受力方向、危险轨迹、动作前摇、发力错线、功法卡点；少写冷意、低语、错觉、不可名状等悬疑氛围**
- **人物台词必须贴合性格、身份、关系和日常场景；制度、地点、费用、物品清单要拆进追问、动作、表格和反应里，禁止连续使用公告腔台词**

## 台词口语化硬约束

- 具体语气类型参照 `23_台词语气类型库.md`；类型库只作为底色，不允许机械套模板。
- 先判断说话人身份：老师、前台、家长、学生、特勤不能同一种腔。
- 再判断人物性格和欲望：同样一句提醒，周冕会短硬，陆秀兰会先问安全和钱，陈屿会用玩笑遮焦虑，顾绍南会拿规则和成绩说话。
- 口语化不是所有人都"接地气"或油腔滑调；性格冷的人可以短，官方可以专业，家长可以碎，但都要像其本人会说的话。
- 角色语气使用"主型+副型"：主型保证人物稳定，副型只随场景微调，不能为了口语化突然换人设。
- 一句台词只承担一个主要信息；超过两项规则/费用/物品，优先拆成动作、表格、内心算账或对话往返。
- 保留日常口语颗粒：如"的话""先""别""上二楼""拿了别搞丢"，但不能让所有人都油腔滑调。
- 官方和老师可以简洁专业，但不能像公告、合同、说明书；要有对象感和现场反应。
- 前台/窗口人物说话要像办事窗口：点表、提醒、补一句注意事项，不整段背条款。
- 学生说话要有年龄感和同学关系，不要替作者解释制度。
- 家长说话先关心钱和安全，不主动说完整设定。
- 写完对话后做一次"去角色名检查"：如果去掉角色名分不出陆衡、陈屿、顾绍南、周冕、沈岚、王成，说明台词需要重写。
- 反例：`观察期七天，课时费暂免，器材借用要登记。资料费不免……`
- 改法：先让人物看表、问钱、追问退不退，再用短句补充：`不转的话退六十。器材上二楼登记借，拿了别搞丢了。`

## 字数与结构

- 硬下限2300字；软目标2600–3200字；必要时可突破3200字
- 第001章：四段节奏（现实压力约700 / 封控流程约600 / 危机判断与行动约1200 / 资格收益+钩约500），总字数落在2600–3200，必要时可突破
- 短段落；对话推动信息
- 常规段控制在20–80字；超过100字先检查是否能拆；超过140字必须拆（压迫场景除外）
- 场景切换、战斗训练、信息释放时，优先用「动作/反应/后果」三段替代长段描写
- 对话信息量较大时拆成「发言/说话人反应/补充信息」，同一发言意图内保留完整段落
- 章末少用抽象总结句收束，如"不是结果，是开始""至少有门""每一步都往里走"；优先用具体动作钩子收尾，例如空着的签名栏、任务编号、未到账补贴、下一次补测时间

## 爽点写法

1. **收益可视化**：每战/每探索写清拿到什么
2. **反差**：被轻视 → 关键出手；低调日常 + 危机强势
3. **双线**：修炼秘境主线 + 亲情友情/官方任务副线
4. **冲突供给**：每5章小冲突，每20章高潮
5. **高武优先**：每章至少推进分数、资格、资源、排名、训练效果、任务权限中的一项

## 训练场景写法

训练是本书核心引擎。每章训练场景必须避免流水账，做到：

1. **每次训练至少有一个具体变化**：偏移率变了、时长变了、新错路被看见、新动作被纠正、组内位置变了
2. **数字不是终点**：写完检测仪的数字后，必须接一个具体后果——陆秀兰看了眼价格、顾绍南扫了一眼对比、周冕写了两个字
3. **训练间轮换写法**：不连续两章用同一种训练结构（站桩→数字→对比→收尾），优先穿插纠错、分组、小测、抽检、同伴反应等不同切角
4. **代价不能不出场**：每章训练如果有洞察参与，必须有体感代价（腿抖、眼酸、头紧）；如果用了一次洞察但没写代价，算违规
5. **每次训练至少有可记录的东西**：一句批注、一行数据、一个被修正的动作、一次被认可的纠错——能让陆衡在训练账上多写一行

## 语言禁忌

- 禁止：`词条`、`校正`、`面板弹出`、`叮系统`、`商城签到`
- 章末排比每3章最多1次
- 不用「宛如、仿佛」堆氛围超过每章2处
- 不用悬疑氛围词堆砌代替判断链；异常描写必须落到主角动作、官方流程或收益变化
- 语气助词服务身份，不服务热闹；`靠北`、`搞什么啦` 等强地域口癖只给特定外地角色，澄江本地人物不用作通用口吻
- 脏口低频使用；灰产角色可粗，学生和官方角色按人物台账区分，不让所有人同一种说话腔
- 前200章正文不直接解释「破界」；只能写封控区、秘境、界隙痕迹、空间错位和官方勘察异常，避免过早抬高到异界修仙口吻

## 反翻译腔写法

都市高武的真实感不来自「留白」，来自「具体」。

读者要的不是猜，是**看见**——看见数字变了没有、表格多了一栏没有、资格卡到手没有。一旦作者用抽象总结代替了具体凭证，读感就会虚。这就是本书需要防的「翻译腔」：不是欧化句式，而是**把本可以落在纸面上的东西，写成了一段气氛。**

### 一条原则

**能让读者看见的东西，就不替它总结。**

- 数字写在检测仪上 → 写数字，不写「他的实力已经有了质的飞跃」
- 回执多了一栏 → 写那栏的内容，不写「这次经历意义深远」
- 补贴到账三百 → 写三百能买什么，不写「虽然不多，但象征着他正式踏上了武道之路」
- 资格卡三十天有效 → 写卡上的日期和限制条款，不写「从今天起，他不再是一个普通学生」

翻译腔的反面不是「少解释」，是**落到凭证上**。每一段推进，至少有一个读者能伸手摸到的东西：一张纸、一个数字、一行批注、一条短信、一声提示音。

### 三种具体病

**病一：预告片旁白。** 作者提前告诉读者这件事有多重要，而不是让读者自己从后果中感受。

- 病句：`陆衡并不知道，这张通知单将彻底改变他的人生轨迹。`
- 健康：`通知单上写着：明早八点，澄江站临时复核点。需携带身份证、学生证、当日武道体测单。`

**病二：总结式收束。** 在角色完成一个动作后，作者替他提炼「这件事的意义」。

- 病句：`这一次，他证明了自己不仅有天赋，更有在压力下保持冷静的意志力。`
- 健康：`沈岚在记录板上写了两个字：合格。`

**病三：情绪代劳。** 作者替角色感动、替角色紧张、替角色觉得「这一刻非同寻常」。

- 病句：`这张资格卡对他来说，意义远大于它本身的三十天有效期。`
- 健康：`他把资格卡翻到背面。违规撤销四个字印在条款最上面。`

### 健康写法自查

写完一段后，问自己三个问题：

1. 这段里有没有读者能「摸到」的凭证？（数字、表格、回执、签名、批注、通知单、资格卡、转账记录）
2. 这句结论是角色自己得出的，还是作者替他说的？（把「陆衡」改成「他」读一遍，像角色心声就保留，像解说员就删）
3. 如果删掉所有形容词和总结句，这段还剩什么？（如果什么都不剩，这段就是空的；如果还剩动作和凭证，就对了）

### 和台词口语化约束的关系

「台词口语化硬约束」解决的是**人物说出公告腔**的问题（如「观察期七天，课时费暂免，器材借用要登记」）。本节解决的是**叙述用抽象替代具体**的问题。

两段合在一起看：**人物嘴里不能背制度，叙述里不能替人物总结。制度靠追问释放，进展靠凭证落地。**

## 审核红线（必须遵守）

- 官方军警特勤正面
- 不写大规模屠城血腥
- 主角不公然对抗国家机构
- 不写灰产倒卖主线
- 境外反派限散修/敌对超凡组织
