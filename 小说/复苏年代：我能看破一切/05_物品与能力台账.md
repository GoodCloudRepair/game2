# 物品与能力台账

## 金手指：万物洞察

| 项 | 内容 |
| --- | --- |
| 觉醒方式 | 001旧楼崩塌事故中灰雾入右眼，渗液后获得 |
| 核心 | **被迫知道物体的结构信息**。不是视觉成像、不是面板词条、不是预知；是"身体知道"——像回自己家，闭着眼也知道门把手在哪 |
| 方向 | 能力越开越重，不是越开越强。物→己→人→活物→死物，每一步看到的都不是新东西，是同一类结构信息越靠越近 |
| 代价 | 觉醒当晚渗灰白薄液；连续使用眼球发热胀跳；信息过载时被迫闭眼；越往深层走，代价从生理渗透到心理——知道的东西回不来 |
| 明面说法 | 周冕对外定性为"感知型天赋" |
| 核心原则 | 洞察不直接加攻击力。他的优势不是"打得准"，是他永远不会在对方面前是盲的 |
