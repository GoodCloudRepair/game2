# 第002章：雾从地铁口上来

## 1. 本章定位

- 所属卷/阶段：第一卷 / 失序开篇
- POV：沈辞
- 时间：D1 11:17-11:25
- 地点：修复中心一楼大厅、后勤室、地下侧廊
- 章节功能：现实救人、规则漏洞破门、追妹路线落地
- 目标字数：2000-2200字；实际字数：2013字

## 2. 本章目标（六问）

1. 主线：表层救妹从远端危机转为楼内可走路线。
2. 核心冲突：呼名电话和灰雾封楼同时逼近，沈辞必须救下母女并找到17号入口。
3. 局面变化：大厅幸存者被稳住，沈辞用无编号旧带打开入口十七秒。
4. 人物新认知：陈勇能把沈辞的判断变成现场执行；沈辞会利用规则缺口而非只躲规则。
5. 新增：蓝牌钥匙、17号入口、无编号破门用法。
6. 章末钩子：入口记录显示`17号 / 11:17 / 已进入检修层`。

## 3. 剧情梳理

- 小唐因回应电话消失；孩子母亲险些回应丈夫，关机后假声音又开始呼叫女儿。
- 母女一靠近楼梯，楼上手机便同时呼叫两人，无法随其他幸存者撤离。
- 陈勇以敲击压住铃声、救回被雾缠住的老周；母亲主动提出走丈夫带她看过的旧档案搬运道。
- 沈辞取得蓝牌钥匙，防火门随即要求登记`搬运件编号`，陈勇的人员工牌遭到门缝白手袭击。
- 沈辞凭蓝牌旧章、门框刮痕和磁带残签判断用途；贴上标签写着`无编号`的旧带后，红灯转绿，入口开门十七秒。
- 门后出现知微的新鲜兔耳箭头、血墨与17号转入记录。

## 4. 人物与关系

| 人物 | 行动/状态 | 本章变化 |
| --- | --- | --- |
| 沈辞 | 关机救人、找钥匙、识破假父亲声、用无编号旧带破门 | 救妹焦灼进入行动，同时第一次把信息差转成主动收益 |
| 陈勇 | 压住人群、从灰雾里救回老周、护送母女 | 从普通保安变成现实执行搭档 |

| 老周 | 带人撤往楼上，一度被雾缠住后获救 | 留在修复中心，不进入地下线 |

## 5. 物品与能力

- 蓝牌钥匙：打开防火门物理锁，仍由沈辞持有。
- 无编号旧带：以标签上的“无编号”骗过搬运件编号核验，损失一段磁层。
- 识名/微校正：本章不新增能力，只使用首章获得的信息与物件定义。

## 6. 规则与伏笔

- 电话、门牌和广播都可成为呼名入口，但本章只保留一次完整险情。
- 17号入口会把`无编号`三个字当作可接收编号，暗示异常流程按字段字面值执行。
- `11:17`首次作为记录时间出现，第003章完成绑定。
