## 使用说明

- 默认POV：沈辞
- 单章字数：不少于2000字，软目标2000-2200字，可上浮至2300字
- 时间范围：`D1 11:05-16:00`

## 第001章 没有编号的档案

- 时间：`D1 11:05-11:17`
- 地点：文书修复中心三楼修复室 / 视频中的文昌路站东端
- 章节功能：死亡开场、妹妹危机、能力最小有效兑现、父亲线落钩
- 核心冲突：沈辞必须在知微被广播编成第十七位后，从同步点名的旧带里抢出一条能立刻救她的路线
- 关键过程：
  1. 视频接通时，知微正在协助陌生男人拖拽受困女人；女人回答救援者的姓名询问后被闸机吞没，并将知微扯进识别范围。
  2. 男人放弃女人、先把知微拽回；广播紧接着将她编成第十七位，沈辞险些喊出她的名字，截断后承诺下楼找她。
  3. 无编号旧带同步喊出知微名字；沈辞看见`可读取：零秒`。
  4. 他以耳后出血为代价微校成十七秒，从断续录音里拼出“第十七位不是名字 / 东端检修口 / 留认得的路”。
  5. 知微因手抖画错第一笔，重新画下兔耳箭头、离开闸机死角，回传一张模糊照片后失联。
- 当章兑现：能力第一次出现就改变妹妹的行动，不再只给已知警告
- 结尾钩子：无电旧带响起父亲声音：`十七号入口，在你们楼里。`

## 第002章 雾从地铁口上来

- 时间：`D1 11:17-11:25`
- 地点：修复中心一楼大厅、后勤室、地下侧廊
- 章节功能：第一次现实救人、第一次规则漏洞破门、把追妹路线落成可走动线
- 核心冲突：大厅被呼名电话困住，沈辞必须救下母女并在灰雾封楼前找到17号入口
- 关键过程：
  1. 小唐因回应电话消失；抱孩子女人险些回应丈夫，沈辞直接关机，假声音随即改叫女儿。
  2. 母女一靠近楼梯，楼上手机便同时呼叫两人；陈勇压住铃声并从灰雾里救回老周，其他人先撤。
  3. 女人因丈夫是地铁检修员而知道旧档案搬运道，主动要求不把异常引上楼；沈辞取得蓝牌钥匙，带陈勇和母女转入侧廊。
  4. 防火门除钥匙外还要求`搬运件编号`；陈勇用人员工牌试门，门缝白手立刻擦损名字，规则只落现场后果。
  5. 沈辞从旧章、门框刮痕与磁带残签判断入口用途；贴上标签写着`无编号`的旧带后，红灯转绿，入口开放十七秒。
- 当章兑现：主角第一次靠规则漏洞开路；知微的兔耳箭头与血墨证明路线真实
- 结尾钩子：门内记录亮起：`17号 / 11:17 / 已进入检修层`

## 第003章 别应门里的名字

- 时间：`D1 11:25-11:40`
- 地点：地下单楼梯、窄平台、第二防火门、服务走廊
- 章节功能：应名规则升级、识名残影初现、11:17与第十七位完成硬绑定
- 核心冲突：第二扇门会借亲属声线收走应答，沈辞必须带人穿过，并从何卫东手里拿到知微确切转入记录
- 关键过程：
  1. 开篇即由假知微在楼下求救，沈辞凭兄妹习惯识破。
  2. 与何卫东、正在撬对讲口救姐的孙浩汇合；站务记录证实知微于11:17被广播改记为17号并进入服务层，沈辞追问她的右手伤势与行动状态。
  3. 孙浩强忍完整姓名呼叫，却被姐姐惯用的`弟`字击穿后收名；死亡前已有撬门、争执和未加载语音三项活人行动。
  4. 沈辞看见`收声`残字后，旧带里的父亲残声意外引来对讲口灰雾，录音也会被收由现场危险坐实。
  5. 他不口头公布答案，直接把损坏磁层的无名底噪送入拾音头；众人过门时父亲残声泄出，沈辞扯断磁带脱险。
- 当章兑现：识名虽未形成完整词条，已第一次转成可执行破局；沈辞救下剩余人
- 结尾钩子：走廊四只钟全停11:17，卷帘门后人影胸前浮出`失名……`，低声说`回家`

## 第004章 第一个词条

- 地点：换乘站外围候车区
- 章节功能：识名首次完整觉醒与第一次怪物规则胜利
- 核心冲突：失名乘客以“回家”执念扑向仍会认出他的人，沈辞必须把刚出现的完整词条变成行动
- 关键过程：
  1. 卷帘门升起即见失名乘客逼近一名旧识，陈勇硬挡失败。
  2. 沈辞救人时读出`失名乘客·回家`，耳后旧伤裂开，听觉开始失真。
  3. 他先误触全区离站广播，怪物反被最近出口引回卷帘门；何卫东指出东端废弃折返线与客运通道分开，沈辞照他的手势切换广播分区。
  4. 沈辞用手动广播把怪物引进折返线；认出怪物的妻子险些再次把它叫回，最终主动咬住称呼，何卫东完成落闸。
  5. 翻倒导向牌下找到知微月票夹和`东端，别走绿门`便签；沈辞在能力余痛中听见`编目`低语。
- 结尾钩子：月票夹内的墨仍未干，知微刚从东端客运通道离开不久

## 第005章 她在三号线

- 时间：`D1 12:00-12:20`
- 地点：东端闸机区、玻璃维护门、绿门与灰门
- 章节功能：追踪章、救学生、让妹妹从被救对象变成主动留路者
- 核心冲突：异常闸机和伪安全绿门挡住路线，程越、许晴困在另一侧，沈辞必须在不再增加死亡示范的前提下打开维护通道
- 关键过程：
  1. 未干墨迹与监控残帧确认知微数分钟前经过，右手受伤但清醒。
  2. 程越、许晴证明她曾救过二人，并交出半截蓝黑笔。
  3. 中间闸机以`通过`诱人，真正安全痕迹贴右墙通往维护门。
  4. 何卫东操作站务释放杆，沈辞与陈勇在闸板反咬中把学生和幸存者带过。
  5. 灰门出现知微笔迹，绿色出口则继续借她声音诱导。
- 当章兑现：救人直接换来监控、笔迹、时间与去向四合一线索
- 结尾钩子：灰门写出：`我去旧儿童医院。别再叫我名字。`

## 第006章 灰雾里的检票员

- 时间：`D1 12:20-12:47`
- 地点：下行斜通道、废弃旧月台、检票口
- 章节功能：第二次完整识名破局、获得妹妹转运硬证
- 核心冲突：旧站检票员只给持有效定义者放行，同行者没有车票，知微旧票根还可能被再次剪名
- 关键过程：
  1. 检票员用打孔钳夹住误踏黄线者的胸牌，沈辞及时用废票替下名字，保住活人。
  2. 识名读出`旧站检票员·验票放行`，众人从票亭寻找废票和员工徽章。
  3. 抽屉底发现`17号 / 已检 / 旧儿童医院接驳`记录和知微旧票根。
  4. 沈辞安排身份与票据顺序，全员过检；自己以“已检不重验”保住知微票根。
  5. 铁门后黑楼梯出现`17号已转入`。
- 当章兑现：不靠新增死亡样本，纯用识名与流程漏洞赢下一关
- 结尾钩子：接驳红字完整显示`旧儿童医院 / 17号已转入`

  3. 林照凭医疗判断抢救，沈辞看见标签残影并阻止错误转运，两人第一次并肩。

  5. 林照拿出12:47分诊单，确认白防护组送来过知微。
- 结尾钩子：分诊单上的`沈知微`被一道笔直红线划掉

## 第008章 不要被重新命名

- 地点：救护点后街、社区药房
- 章节功能：物品识名兑现、救命收益、`共鸣体-17`硬落地

## 第009章 旧城天桥

- 时间：`D1 14:20-15:20`
- 地点：旧城天桥、高架连廊、医院外围
- 章节功能：动作变体章、官方提前介入证据、抵达医院门域
- 核心冲突：通往医院的正路已经沉雾，一名携带封控图的城防外勤挂在断桥维修架上，沈辞和林照必须在广告牌改向前把人和路线一起抢回来
- 关键过程：
  1. 开篇即救挂桥外勤，错误导向牌不断把人往雾里送。
  2. 沈辞以电缆固定，林照剪断被雾拖拽的救援绳，救人成功但无法再下桥救深雾区人群。
  3. 外勤交出A级异常区折图与`收容点-4`通行牌，确认官方10:50已经圈定旧儿童医院。
  4. 他只来得及说白防护组把`17号`从侧门转入，随后被送回救护点；沈辞、林照继续前进。
  5. 医院外墙开始门域化。
- 结尾钩子：`海陵市旧儿童医院`一笔笔改成`第三收容门`

## 第010章 门后有人认出他

- 时间：`D1 15:20-16:00`
- 地点：医院外围、旧连廊、住院楼前厅
- 章节功能：前10章收束、进入医院、反向识别抬高身份线
- 核心冲突：第三收容门的入口不断错位，沈辞必须在路径彻底改名之前带林照进入，同时避免被门域先行归档
- 关键过程：
  1. 转运床从错误入口自行滑出，床上尸体胸牌被抹空，入口危险立刻落地。
  2. 沈辞筛出`暂行`旧连廊，林照用血迹、轮痕补现实判断，两人通过错位门廊。
  3. 前厅残留官方转运床、封控箱、白防护服与`请按编号转入`提示，确认收容行动失败。
  4. 半失名外勤尸体额角留有`编`字残痕；沈辞接触读取时遭遇反向识别。
  5. 咨询台后更多东西随之转头，林照拔刀托底。
- 结尾钩子：尸体睁眼说：`编目师……你终于回来了，沈辞。`
