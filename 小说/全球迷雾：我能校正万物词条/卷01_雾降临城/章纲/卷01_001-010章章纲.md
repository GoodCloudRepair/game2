## 一、重构结论

现行结构的主要问题不是单章事件不够，而是事件彼此太完整：到新地点、看路人出错、沈辞读出规则、解决问题、拿到妹妹线索、妹妹刚离开。每章都能独立成立，却导致读者在第二章以后迅速识别出固定模版，妹妹线也长期停留在“差一步”的假推进。

方案B把十章压成一条不可中断的因果链：

`视频里看见知微被编号 → 冲入同一条旧转运通道 → 现实中看见她 → 隔门碰到她 → 因自己的半声呼名和她的主动选择再次失去她 → 借失名者抢回转运方向 → 追上白防护转运车 → 与她正面交流 → 她为护住同车孩子主动留在17号链上 → 沈辞与林照追进旧儿童医院 → 尸体反向叫破“编目师”`

这样，前十章的主问题始终只有一个：沈辞能不能在知微被流程彻底改成“17”以前追上并带走她。

## 二、第011章接口与后文硬锚点

### 必须原样抵达的第011章接口

1. 第010章末地点仍是旧儿童医院住院楼前厅。
2. 沈辞与林照共同进入，关系只到“彼此认可专业判断并愿意托底”，不能提前写成生死绑定或暧昧。
3. 前厅仍有白防护、城防外勤与病人的尸体，仍显示一次官方收容行动已经失败。
4. 沈辞接触额角留有半个`编`字的外勤尸体，遭到反向识别。
5. 结尾原句不变：`编目师……你终于回来了，沈辞。`
6. 第011章才第一次完整打出`共鸣体-17`；前十章只能出现`第十七位`、`17号`、姓名被划除和异常转运，不提前泄露完整术语。

### 前十章不能删除的后文锚点

- 无编号旧磁带：保留第001章十七秒微校正和父亲旧声；它是父亲线与能力代价的首个实物。

- 陈勇：必须在前四章被写成能扛事、会救人、骂归骂但不弃人的行动者。第005章让他留在地铁出口组织幸存者，保证第107章以后回归不突兀。
- 林照：提前至第005章登场，但职业逻辑、独立判断和冷硬救人方式不变。

## 五、逐章章纲

## 第001章 没有编号的档案

- 时间：`D1 11:05-11:17`
- 地点：文书修复中心三楼 / 视频中的文昌路站东端
- 本章目标：在保留现有强开场的基础上，把沈辞从“冷静观看者”改成来不及救、却一直试图抓住妹妹的哥哥。
- 开篇事件：视频接通时，一个女人正在被闸机吞没；知微和旁人拼命拽她，女人回答姓名后彻底消失，知微被广播记为第十七位。
- 核心冲突：沈辞不能赶到现场，只能在知微被闸机与假人夹住时，从同步开口的无编号旧带里抢一条可执行路线。
- 关键过程：
  1. 沈辞险些在屏幕前喊出知微全名，临时改口让她看右边、看熟悉的标记；这一截犹豫先暴露他的情绪，不把他写成无波动的规则机器。
  2. 旧带显示`可读取：零秒`。他以耳后出血为代价微校到十七秒，拼出“第十七位不是名字 / 东端检修口 / 留认得的路”。
  3. 知微画下兄妹都认得的兔耳箭头，躲过假沈辞，进入只剩红色`17`的服务门。
  4. 她没有被动逃跑；进门前还把那个受伤男孩往门内拽了一把，建立第012章证词的源头。
  5. 视频断开，联系人和同事记忆开始被抹除，修复屏上的十七秒波形却仍然存在；沈辞带走断带下楼。
- 当章新知：`第十七位`是流程位置，不是知微的名字。
- 位置变化：知微从闸机区进入17号旧服务通道；沈辞从修复室转为追击。
- 能力与代价：只允许一次十七秒微校正；耳后出血、短暂黑视，不能出现成熟能力说明。
- 人物变化：沈辞第一次为了眼前的人放弃把残音修完整，行动优先于职业洁癖。
- 结尾钩子：无电旧带响起父亲声音：`十七号入口，在你们楼里。`
- 禁止写法：不总结闸机规则；不让沈辞在死亡后冷静复盘三段逻辑；不提前出现“系统”“权限”“技能”。

## 第002章 十七号入口就在楼下

- 时间：`D1 11:17-11:27`
- 地点：修复中心一楼、后勤搬运道、地下旧联络层
- 本章目标：第二章必须立刻给“追上了”的真实回报，不能再用一组新路人挡满全章。
- 开篇事件：沈辞冲到一楼时，后墙那扇从未使用的搬运门已经自行打开一线，门内不断传出与视频相同的床轮声。
- 核心冲突：门只把有旧档痕迹的物件当成合法搬运件，活人靠近就会被擦掉胸牌姓名；灰雾正在把入口往墙里封回去。
- 关键过程：
  1. 陈勇先用警棍和人力压住混乱，让楼内其他人撤高，不再安排小唐消失与母女完整支线。
  2. 他用工牌试门，名字最后一笔被白手擦损。沈辞据此确认门认“搬运件”而不认工作人员。
  3. 沈辞将无编号旧带贴上旧入库章；白手连续刮擦空白编号却无字可删，入口被迫开放十七秒。陈勇不问清原理，先跟进去替他卡住门。
  4. 何卫东从地铁侧的检修层赶到。他只提供一个现实信息：修复中心地下搬运道与文昌路旧站服务层曾共用一段物资通路。
  5. 透过两层钢网，沈辞第一次在现实中看见知微。她右手流血，正扶着第001章那个男孩的转运床；几名白防护在催促他们进入下一段。
  6. 知微也看见他，用指节在床栏上敲两下，随后指向下方，不喊他的名字。
- 当章新知：修复中心与地铁旧站并非两处副本，而是同一条废弃转运体系的两个入口。
- 位置变化：沈辞进入与知微相同的地下联络层；两人的空间距离从一条街缩到两层钢网。
- 能力与代价：只能看见门上极短的`搬运`残影；真正开门依靠旧章、磨损和工牌被擦三项现实证据。
- 人物变化：陈勇从“楼内保安”升级为会先救人、敢跟进未知通道的行动者。
- 结尾钩子：钢网另一端的转运床开始下沉，沈辞看见知微把手伸出栏缝，离他只差一扇门。
- 禁止写法：不新增电话应名死亡；不写“记录显示知微刚走”，必须让沈辞本人看见她。

## 第003章 隔着门别叫我

- 时间：`D1 11:27-11:40`
- 地点：地下联络层、升降隔离门、旧站服务平台
- 本章目标：前三章内完成一次真正重逢，也完成一次由人物情感造成的失败。
- 开篇事件：升降门只剩半人高，沈辞扑过去抓住知微从栏下伸出的手；她的手很冷，虎口有新伤。
- 核心冲突：白防护组要把男孩和知微送入旧站转运线；沈辞想立刻拉她出来，知微却发现男孩一旦离开转运床，腕上的灰圈就会收紧。
- 关键过程：
  1. 兄妹第一次正面交流不用互报姓名。知微先说“别叫”，再告诉他男孩不是17、自己暂时能压住床栏上的广播。
  2. 她把浅蓝月票夹塞过门缝。里面保留旧月票，并新塞入被水打湿的便签；纸上只写到`我先送他，别——`，最后半句未完，方向用兔耳箭头代替。
  3. 沈辞试图掰开隔离门。门内父亲旧声突然叫知微的小名，知微的手被门沿夹住，他下意识冲出半个`知`字。
  4. 仅仅半声，门上的空白栏便开始长出她姓名的第一笔，男孩腕上灰圈也转向她。沈辞亲眼看见自己的声音让转运流程重新抓稳她。
  5. 他试图把门上的`转入`强行改成`放行`，但现场没有任何“放行”依据，灰字碎掉，耳后伤口再次裂开，右耳失听。这是明确的越界失败。
  6. 沈辞发现腕表仍有十三分钟、交接板尚未签字，便依据“交接未完成”的现实把错误的`转入`压回旧章`待交接`。姓名停止生长，平台切往人工东线；知微仍主动按下闭锁，带男孩继续下送。
- 当章新知：亲属呼名会让17号流程更准确地抓住知微；能力不能创造不存在的`放行`，却能依据现场事实纠正一处错误状态。
- 位置变化：两人短暂接触后再次被门分开；知微进入人工东线，沈辞取得月票夹、东线方向和不足十三分钟的追击窗口。
- 能力与代价：越界改动失败并造成右耳失听；随后借空白交接板、倒计时与旧章完成一次不可复制的事实微校正。
- 人物变化：知微第一次作出与哥哥愿望相反但有理由的决定；沈辞第一次承认“追到她”不等于能替她决定。
- 结尾钩子：门彻底落下，白牌仍标`17`，下方却多出`待交接 00:12:39`；沈辞起身追向东边。
- 禁止写法：不把知微写成讲规则的NPC；她只说自己看见的结果，不解释机制。

## 第004章 失名者只认回家的路

- 时间：`D1 11:40-11:46`
- 地点：文昌路旧站服务平台、废弃折返线、地面坡道
- 本章目标：用一场直接服务追妹线的规则战完成识名第一次完整胜利。
- 开篇事件：`待交接`倒计时已经开始，一名失去五官的旧乘客从停运列车里下来，反复说“回家”，堵住通往人工东线的唯一追路。
- 核心冲突：沈辞既要带陈勇、何卫东穿过站台，又要在倒计时结束前迫使人工东线转向地面，不能让知微重新落回地下医院接驳线。
- 关键过程：
  1. 怪物不扑所有人，只追仍认得它的旧站务广播和回家路线；陈勇硬挡时被甩开，但仍拖回差点靠近的人。
  2. 沈辞第一次读到完整词条：`失名乘客·回家`。他先误开全区离站广播，怪物朝最近出口折返，反而堵住众人，先让错误发生。
  3. 何卫东指出废弃折返线曾是旧站职工回程线，陈勇去扳机械闸，沈辞只负责把词条和现场用途拼起来。
  4. 三人把怪物引入折返线。它撞乱旧调度，使原本向地下医院接驳线行驶的白防护转运车被迫改走地面应急坡道。
  5. 沈辞从月票夹内湿便签和未干墨迹确认知微早已预料到“回家”的东西会追广播，她留下的不是标准答案，而是供哥哥判断的半步证据。
- 当章新知：失名者仍会被生前最重的执念固定；异常流程之间也会彼此干扰。
- 位置变化：17号转运由地下深线被迫切到地面；沈辞夺回肉眼可追的方向。
- 能力与代价：首次完整识名；右耳从完全无声恢复少量低频，但高频缺失进一步固定，短时仍听不清何卫东的喊声。
- 人物变化：沈辞第一次赢，但胜利来自三人协作与知微预留证据，不是他独自公布答案。
- 结尾钩子：地面坡道尽头，知微的手从白车门缝伸出敲了两下；沈辞回敲时，坡顶另一个人正冲白车喊停，第005章林照直接接入。
- 禁止写法：不安排失名者家属现场痛哭认人；不再做完整路人死亡示范。

## 第005章 白车不收家属

- 时间：`D1 11:46-12:18`
- 地点：文昌路站地面应急坡道、临时医疗点、白色转运车
- 本章目标：林照登场必须直接撞进17号主线，而不是先做一章独立医疗副本。
- 开篇事件：林照把手卡进即将合拢的车门，要求白防护先让她检查车里的男孩；门内的人只回答一句：`白车不收家属。`
- 核心冲突：男孩缺氧，知微右手失血，白防护却只核对床号和交接栏；沈辞一靠近就被判成17号家属，反而触发车辆闭锁。
- 关键过程：
  1. 林照不认识沈辞，也不信他的能力，只以瞳孔、脉搏、出血和氧流量指出“车里两个人都还在变化，不能按空床转走”。
  2. 沈辞看见交接牌上的姓名栏正在变浅，但他不直接报答案，只告诉林照哪一张牌的墨迹覆盖了原始血指印。
  3. 林照以医疗事故责任强行拖延白防护，现场补氧并压住知微的伤口；知微始终不回答任何姓名，只用两下敲击回应沈辞。
  4. 陈勇负责把从旧站出来的幸存者带到临时点，并留下组织出口与接应何卫东。这里完成他与主线的阶段分流，保留后续回归空间。
  5. 白防护发现17号交接超时，车辆开始自行锁门。林照以“男孩必须由医生陪送”为理由上车；沈辞被家属判定挡在外面。
  6. 知微在门内悄悄拨开后门底锁，给沈辞留下能抓住的缝。
- 当章新知：白防护转运组正在把活人当成交接项处理；17号的家属关联会反过来加强闭锁。
- 位置变化：知微和男孩进入白车；林照合法上车，沈辞只能从后门强行追入。
- 能力与代价：本章不升级能力，只强调它必须与林照的现实医学证据交叉验证。
- 人物变化：林照不是被沈辞说服追妹，而是因病人仍需她、转运流程又明显错误而主动上车。
- 结尾钩子：白车启动，沈辞抓住知微留出的门缝，被拖出数米后翻进车厢；里面的人齐齐转头，却没有一个人先看他的脸。
- 禁止写法：不设置假药筛选；不让林照初见就无条件信任沈辞。

## 第006章 转运车里没有病人

- 时间：`D1 12:18-12:35`
- 地点：行驶中的白色转运车、旧城封控路段
- 本章目标：把追逐搬进移动空间，让知微、沈辞、林照和白防护第一次同处一个封闭场域。
- 开篇事件：沈辞滚进车厢后，最近的白防护队员没有问他是谁，只低头补写清单：`随车物，一件。`
- 核心冲突：车内清单只认床号和件数，不认病人；谁试图以姓名叫醒转运对象，谁就会被补进交接栏。
- 关键过程：
  1. 林照已经给男孩接上氧，知微隔着两张床看见沈辞，先用眼神制止他开口。
  2. 一名尚清醒的白防护队员试图纠正清单，写下“病人两名”，字却在纸上被改回“交接两件”；他不是反派，而是被流程压住的失败执行者。

  5. 知微趁白防护处理路线错误，踢松车内隔离栏；沈辞与林照进入她所在的后半车厢。
  6. 车辆在旧城封控断口急停，白防护人员被甩向前舱，兄妹得到极短的独处时间。
- 当章新知：17号链不只是“改名字”，还会把活人降成便于运输的项目；白防护组也在被它吞噬。
- 位置变化：沈辞终于与知微同车，物理距离只剩一条束缚带。
- 能力与代价：识名过载造成听觉误判；林照第一次真正救的是沈辞的判断，而不只是他的伤。
- 人物变化：沈辞开始接受别人可以否定他的读法；林照认为他有用但不可靠，专业信任开始形成。
- 结尾钩子：沈辞掀开知微手腕上的纱布，看见皮肤下方不是伤口，而是一圈正在自行收紧的红色`17`。
- 禁止写法：不把车厢写成又一组“选三扇门”；不让白防护统一脸谱化。

## 第007章 她先说别叫我

- 时间：`D1 12:35-12:53`
- 地点：停在封控断口的白车后舱
- 本章目标：完成前十章最重要的兄妹正面戏，让“再次失去妹妹”来自知微的主动选择和沈辞能力边界，而不是作者强行关门。
- 开篇事件：沈辞刚碰到腕上的红圈，知微先抓住他的手腕：`别改。`
- 核心冲突：沈辞有机会直接剪带带她下车，但红圈每松一分，男孩腕上的灰痕便加深一分，车外也会多响一次呼名广播。
- 关键过程：
  1. 知微只交代亲眼发生的事：她从闸机救下男孩后，17号一直在两人之间移动；她不再回应，数字才暂时停在自己身上。

- 位置变化：兄妹完成一次有效交流后主动分开；沈辞从“抢人”转为追查整条交接链。
- 能力与代价：活人身份校正失败，耳后出血加重；不出现任何可选择的改名菜单。
- 人物变化：沈辞真正意识到知微已经在独立作战；知微明确反对哥哥把救她当成唯一正确答案。
- 结尾钩子：白车驶离时，车尾交接牌上的`沈`字被一笔抹掉，只剩`17号 / 姓名缺省`。
- 禁止写法：不煽情拥抱，不让兄妹把童年往事讲给彼此听；感情落在抓手、停手、推开和两下敲击上。

## 第008章 名字划掉以后

- 地点：旧城封控街区、废弃转运登记点、医院外围道路
- 本章目标：在失去目视后仍保持追逐感，用被删身份与白防护残存证据推进，而不是再进药房做新副本。

## 第009章 只能救一个方向

- 时间：`D1 14:10-15:15`
- 地点：旧城天桥、高架连廊、医院外围
- 本章目标：保留现版天桥动作优势，但让“救人还是追妹”成为沈辞真正付出时间的选择。

- 核心冲突：沈辞若继续追车可能赶上知微；若停下救人，白车一定消失。但外勤既是活人，也是进入医院仅剩的现实路线持有者。
- 关键过程：
  1. 沈辞看见白车远去后仍停下。不是为了“救人换地图”，而是知微第007章的选择迫使他承认其他人也不能只被当成线索。
  2. 林照控绳、判断伤势，沈辞下维修架；主要救援依靠电缆、受力点与两人配合，不用能力一键解题。

- 位置变化：白车消失，但医院入口与真实路线被锁定。

- 人物变化：林照看见沈辞不是只救妹妹的人；沈辞也认可她会在不可能全救时给出清楚边界。
- 结尾钩子：`海陵市旧儿童医院`一笔笔改成`第三收容门`。
- 禁止写法：不把未能救下的人写成纯粹催泪尸体；结果停在“无法再下去”，保留现实沉重感。

## 第010章 门后有人认出他

## 六、三条进展曲线核查

### 1. 妹妹距离曲线

`屏幕可见 → 现实目视 → 隔门触碰 → 失去 → 追上车辆 → 同车 → 正面对话 → 妹妹主动留下 → 锁定医院 → 进入同一门域`

这条曲线每两章至少产生一次不可逆变化。第003章和第007章都必须让兄妹真正交流，不能再用留言、监控和目击证词替代。

### 2. 能力与代价曲线

`微校十七秒 → 读到残痕并利用无编号 → 越界改动失败后按事实压回待交接 → 首次完整识名 → 与医学事实交叉校验 → 过载误听 → 活人身份不可改 → 单耳短暂失听 → 不靠能力完成救援 → 遭反向识别`

前十章没有稳定`改名`。所有可见效果都来自读取不完整称谓、微调残损媒介或利用已存在的流程漏洞，不能写成凭空改写世界。

### 3. 人物关系曲线

- 沈辞—知微：保护冲动 → 真正追上 → 因呼名犯错 → 看见知微救人 → 尊重她的选择 → 改为追流程而非抢人。
- 沈辞—陈勇：陌生保安 → 现实救援搭档 → 能互相托付动作 → 第005章自然分流，等待后文回归。
- 沈辞—林照：互不信任 → 各持一半证据 → 她纠正他的误听 → 共同确认能力边界 → 建立“两次实触”协议 → 稳定专业搭档。

## 七、跨章去AI感约束

1. 前十章只允许第001章完整展示一次“报出姓名后被吞”。后续不再让新NPC依次犯同一错误供主角总结。
2. 同类文字提示不能连续成为解法。提示只能制造压力，最终判断必须至少落在人物动作、物理痕迹或关系记忆中的两项。
3. 知微不能连续通过便签、涂鸦、监控、目击者“刚刚离开”。她必须在第002、003、005、006、007章直接在场并改变局面。
4. 每章最多一个关键新概念：第十七位、旧转运通路、亲属呼名、失名执念、白车流程、交接项、活人身份边界、删名、官方提前介入、反向识别。
5. 沈辞至少出现三次非最优反应：第001章险些喊名、第003章半声呼名并强改失败、第006章因听觉失真判断错误。错误必须产生后果，但不能靠降智。
6. 林照不能成为“医疗版说明书”。她只确认身体事实、风险和自己不知道的部分。
7. 白防护不能整齐说规则。他们的行为应有分歧，部分人机械执行，部分人试图纠正，部分人已经被流程降成工具。
8. 章节结尾不能十次都用红字。十章钩子依次使用：父亲旧声、现实目视、主动关门、车门敲击、强行登车、腕下红圈、姓名被抹、坠桥外勤、楼名改写、尸体开口。
9. 前十章不能把`克制`写成`无情绪`。每个核心高压场景至少落一处会改变动作、发声或选择的状态细节；从声音、身体、杂念、私人动作中选一至两项，不堆满。
10. 沈辞的情绪裂口重点落在四处：第001章险些喊出知微全名；第003章半声呼名使流程重新抓住她；第007章明明抓到妹妹却必须停手；第009章看着白车消失仍转身救人。其余章节保持低烈度余波，不把每章都写成同一强度。
11. 知微、陈勇、林照和普通人必须有不同的压力反应。知微越怕越先护住别人，陈勇会骂会喘但先顶住实物，林照急在检查和命令顺序，普通人允许哭乱、说错和求不合理保证；不能共用同一套`脸白、抿唇、指节收紧`。
12. 对话不能只剩台词。关键发言前后补能改变语义的一处状态，例如气短导致句子断开、嘶吼暴露失控、声音放轻是怕触发呼名、重复称呼是人在慌乱中抓住唯一熟悉之物；禁止用三层近义形容词堆出假情绪。

## 八、六问总检

1. 沈辞前十章要什么：追上知微，并阻止她被彻底改成17号。
2. 谁持续阻止他：不是十只轮换怪物，而是已经启动的旧转运流程，以及被流程绑架的白防护行动。
3. 他为什么不能直接带走知微：亲属呼名会加强定位；17号与男孩产生现实联动；当前能力无法无代价改写活人身份链；知微本人也拒绝拿别人替位。
4. 十章后失去了什么：知微的公开姓名正在被抹除，沈辞的右耳出现持续损伤，兄妹不再能用名字确认彼此。
5. 十章后得到了什么：沈辞从追人升级为追流程，获得月票夹、林照的专业协作、医院真实入口与对“识名并非单向”的第一次警觉。
6. 读者为什么必须点第011章：沈辞终于进入接收17号的医院，却先被尸体叫出一个他自己不知道的名字——`编目师`。

## 九、落地顺序

本方案不能直接从第001章逐章盲改。正式执行顺序为：

1. 先固定第003章兄妹隔门戏和第007章兄妹正面对话，这两章决定整套重构是否成立。
2. 再写第002、004、005、006章，把追逐路线与转运因果接实。
3. 调整第008、009、010章，确保第011章接口一个字不改也能接上。
4. 最后回修第001章，使开头埋入男孩、两下敲击和月票夹三个后续动作锚点。
5. 十章正文全部通过后，再一次性同步章节总表、时间线、人物状态、关系、物品、能力、伏笔和思维笔记；十章正文未全部定稿前不污染正式台账。
