# 第034章 广播先叫学号

教室里的安静比病房更像标本。

所有人坐在不能出声的地方，被一排排旧课桌隔在不能碰到别人的距离里。藤黄色旧灯管把每个人照得蜡黄，连呼吸都贴着桌面不敢往上浮。

讲台顶灯调得很低，只照亮黑板左半截——留半张讲桌在阴影里，像在等谁才该被全照出来。

广播响了。

男声，吐字慢而清楚，却不像学校里的老师。

它不止在说话，更在数数。

先从班级叫起。

`第二排、第七座。`

被叫到的男生愣了一下才起身，膝盖碰到桌底发出轻响，然后迅速捂住嘴压住咳嗽。讲台上那半张轮廓被顶灯从阴影里拉成清晰的半身形。

它推了一下眼镜，开口说：

"17号，跟着我的口令走。"

语气平淡，像这句口令已发过很多遍，连语气都不需要换。

教室里陆续有人被叫。第五排、第三座；第九排、第十一座。每个编号对应一个真正的位置。每叫过去一个，讲台上那个人就对着广播说一句"跟上"。

第十七排没有人被叫。

沈辞坐在第四排一座，因为教室里根本没有几排。

可被叫到"第十七排"的时候，他耳膜嗡了一下，像那行数字不是从喇叭里落下来，是从他旧床号上剥离后追进来，找到他身上。

广播没有叫"17"。

它叫的是"第十七排、第二座"。

讲台上那个人听见这串编号之后顿了顿。

只有一秒。沈辞看见灯往下压了半寸，照到桌上新位置，像在确认该翻哪一页。

然后广播一次性叫了五个位置。那五个座位都空着——实打实的空桌椅，连课本都没留下。可讲台上那个人照常回答"跟上"，好像那些空位上都坐着人。

他每说一次"跟上"，黑板左边那截粉笔槽里就多出一小截断粉笔，色调偏黄像放了很久。粉笔断得整齐，不是掰断，是写断的。像刚刚确实有人在这里写东西被拿走得太急，连粉笔都来不及放下。

空位上找不到人，只留下某些用完的痕迹，像被精准擦掉的板书。

粉笔槽里多到第六截断粉笔时，前排右数第三个女生低下头。头顶比旁边人矮一截，她把两只手压在课本下，指节泛青，食指指甲掐进拇指指腹。那不是紧张——是周围空气逼她别抬头看那些空的座。

广播忽然停了两秒，重新出声。

这一次不叫学号和座位了。

`请第十七排的十七号来接新课表。`

声音没变。

但教室里所有坐着的同学几乎同时微微往前倾了一下，像一条看不见的线从他们背部穿过去，把他们往讲台方向一拉——又不敢真的看。

讲台上那半张脸缓缓转向第四排。

"十七排，十七号。到你了。来黑板前。"

沈辞缓缓站起来。没推椅子，膝关节却自动弹响了一声，像关节比大脑先给出了反应。

他从过道走过时，后排有个男生的手在课桌下轻轻一摆，往里挡了一下，不是推他——是告诉他别去。

沈辞没停。

他知道自己不是被叫去的"十七排十七号"。

但黑板上的东西必须站到讲台上才能从背面看清楚。

黑板上的粉笔字比刚才更多。

起初只是几行数学公式。翻过来一看，那些"公式"根本不是数学。

`座位 = 某节点 → 班级 = 某项目 → 区域 = 门层 → 楼层 = 门级别 → 教学楼 = 门形态`

整块黑板的逻辑是从座位、到班级，一直画到楼。每一条后面都划着粗细不同的杠，有些被抹过又重写。

最后一行最乱，几乎是被用粉笔戳上去的。

`教学楼 = 某个可以持续扩张的栖门。`

沈辞弯腰去捡粉笔槽里多出来的断笔，拿到第三截时碰到纸片。不是课本纸，是某种封塑小片被掰断抛在这里。很轻，拿起来没声音。

纸上用圆珠笔写着五个字，很急但很稳：

`别坐五排三座。`

字条第一眼扫过去是句普通的座位提醒，可沈辞脑子里直接砸进来一个名字——`沈知微`。

是她的笔迹。连塑封条的材质都是她用过的那一种。

她在用和以前一样的方式往他面前塞信息。

沈辞把纸条压入掌心，没低头多看。然后转向讲台侧面的登记册——翻到"十七排"那页。

第十七排，第二座已被勾掉。被勾掉的人姓氏只有一个字：`沈`，没有名。

勾掉动作很快，但沈辞注意到——只勾横笔画，不碰竖笔画。"沈"字竖划完好，横划被粉笔或硬物一笔扫过，像故意留下笔画痕迹给后来者辨认。

更右侧还有一处留白——第十七排，第一座。椅子还空着，却没被勾掉。像在等什么人坐上去。

教室后排有人轻轻翻了一页，又立即压住。

沈辞把登记册页码记在心里，回到自己座位。黑板左上角开始渗出暗黄色液痕，从旧粉笔灰里慢慢往外渗。像这间教室刚被丢在某个更深的液层里，水还没把字全部吞掉。

讲台上的人把半张脸重新埋进阴影，广播开始叫下一组。

沈辞把那张字条折了又折，直到塑封尖角刺进掌心才停。

知微在这里出现过。

不止是来过，是在离开这间教室前，用同样的方式给后面的人留了一口喘息的空隙——让他知道第五排第三座下面是动的，让她知道有人会发现这条线索。

可他还有更麻烦的问题要在心里拼。

讲了那么多遍"跟上"，登记册上那些被勾掉的人在哪排队。

每间教室是栖门的不同层级，每层的"跟上"就是从上一层往下走一层。

那么所有被叫出去的学生，最后都会汇到同一个出口。

他坐直了一点，盯着黑板最下面那一行被粉笔戳上去的字，重新在心里把它和自己的旧床号连上线。

17号不是在离开这些门。

他只是在按已有人走通过的路，一层层往里。

广播又响了起来。

这一次叫的号码更近了：`第十六排、第四座`。他旁边那个自始至终没抬头的人终于动了一下。

沈辞把手心里那张字条塞进袖口折缝里，在那人起身前多看了他一眼。

整个教室还剩将近三分之二的空桌椅。

可沈辞知道，这里从不缺人。
