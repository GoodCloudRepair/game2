# 关系台账

关系不是静止设定，而是会随着章节推进不断变化。  
这份台账只记“已经发生变化的关系”和“未来准备推进的方向”。

| 关系双方 | 当前关系 | 核心纽带/矛盾 | 最近变化 | 后续方向 |
| --- | --- | --- | --- | --- |
| 沈辞 / 沈知微 | 兄妹，强保护关系，已绑定封门结构 | 沈辞想救她，知微却正在压住城市门缝 | 第108-112章知微继续稳住17格，帮沈辞压住外线回执和真门名倒写反噬；沈辞在撤城与替换方案前明确拒绝把她当作一次性锚点 | 第113章必须用规则证明`共鸣项不可替换`，不能只靠情绪反驳顾焰 |
| 沈辞 / 林照 | 高危搭档，克制慢热的感情尚未说破 | 理性与秩序感上的互相识别；沈辞习惯隐瞒自身代价，林照不能接受他把自己当工具 | 第115-116章林照开始越过纯工作口径追问沈辞的身体状态；第117章沈辞第一次说清自己只剩一息，并在她的催促下及时松手，关系落到具体的风险坦白和服从止损；后续旧稿仍需逐章补足私人起伏 | 卷02越过纯工作边界但不自认；卷03让读者看明白并出现真实冲突与私人选择；卷04前后互相确认；卷05后共同承担灯港责任 |

## 沈辞 / 顾焰长线反转确认

- 顾焰不是一直潜伏的好人。他和沈辞的前期冲突全部有效，尤其第112-113章将知微视作可替换共鸣项，是其真实价值观。
- 顾焰发现自己也是`完整替换样本`后，最初的反抗可以只为自保；只有当他愿意放弃最高权限、黑箱主钥和制度承认，阻止同样的事落到别人身上，关系才真正进入盟友阶段。
- 沈辞可以接受顾焰在终局并肩，不等于替受害者原谅他。两人长期保留方法冲突，可靠来自顾焰肯为自己的判断付代价，不来自性格突然变好。
| 沈辞 / 回澜中学深层秩序 | 互相追索，开始正面套名 | 学校在处理知微的同时，也想把沈辞按`沈`姓写进同一条流程 | 第071章学校已把知微按`17`号观察位完整移交白栏，关系已从“正面对抗对象归类体系”推进到“看清学校只是收名链前段，它真正会把对象交给更外层系统” | 从拆学校收名链，走向拆它与官方共用的整条对象转送链 |
| 沈辞 / 沈父 | 缺席型亲子关系，方法边界已显 | 真相缺失、立场成谜；未来核心不是误会解除，而是谁有权决定必要牺牲 | 第106章父亲旧句露出`别替门取新名 / 回旧边 / 锁其所止`，关系从“父亲曾走过里路”推进到“父亲留下封门错路边界” | 卷03以前从寻找、怀疑推进到按半句方法读门，不揭完整真相；卷04坐实父亲阻止过大归档也承担过局部牺牲责任，沈辞理解目的但不接受其方法 |
| 沈辞 / 归零会 | 尚未正式接触，只接触过无法命名的记号与匿名护名行动 | 双方都反对永久编目，但沈辞不会因此接受彻底失名或预定少数人牺牲 | 第163章父线残角出现缺口圆，第230章同一记号出现在待核女人布包上；匿名者曾教她藏好本人旧纸，但沈辞不知道对方身份或组织名 | 卷03最多再补一次匿名后果；卷04正式接触并看见内部做法冲突；卷06分裂；卷07按具体行动形成敌对或临时合作 |
| 沈辞 / 门域核心 | 已进入真门名倒写与封门夜战段 | 核心只认未写圆活项，并不断切断门外关系 | 第108-112章核心以外线回执稳内名，排除文昌回头线后开始倒写真门名，同时反读沈辞自身词条；第一栏失守后撤城和替换方案都暴露定层被接管风险 | 后续继续读倒写笔画，但必须防止活项被门反读和共鸣项被工具化 |
| 沈辞 / 城防局 | 封门协作，仍不完全信任 | 主角未来将被纳入官方体系 | 第103-107章城防局外锁只锁外名，杜衡承认内名必须由沈辞读，同时调度外线断流程 | 从被官方利用，走向“官方必须争取他”的卷尾落点 |
| 沈辞 / 财团联盟 | 外缘记录与工具化利用关系 | 财团代表旧秩序和效率优先逻辑 | 第110-112章顾焰黑箱连续记录门反读、文昌动线与共鸣项替换可行性，财团线从记录沈辞价值推进到尝试替换知微源位 | 从信息差和试探，走向“能不能把人当参数”的正面冲突 |

## 开局修订关系补记

- 沈辞 / 沈知微：第001—003章完成`隔屏看见 → 隔网目视 → 隔门抓手`的连续追近。知微三次都把男孩安全放在自己脱身之前，并用兔耳、月票夹和两下敲击反向留路；沈辞第003章因保护欲漏名、强改`放行`失败，随后依据真实交接状态抢回十三分钟。第004章知微再用未干蓝黑墨给半步方向，沈辞把它与旧站结构拼成路由，章末两下敲击重新建立联系。第005章沈辞为减弱家属闭锁主动退到黄线外，知微在车辆启动前拨开后门底锁让他登车。兄妹从单向保护推进为隔着流程互相留路。
- 沈辞 / 何卫东：第002章由旧货道和门内两下敲击建立临时同行；第003章何卫东负责手动开关、旧站路线和阻止沈辞进门，沈辞则用异常残痕把`转入`压回`待交接`；第004章沈辞主动要求何卫东站到左侧说话，并用其共用配重判断修正自己的广播误判。两人的关系从带路推进为设备现实与规则判断互相补位。
- 沈辞 / 陈勇：第002章由顶门和过门建立行动信任；第003章陈勇在沈辞越界受伤时负责把人拖回；第004章即使沈辞按错广播，陈勇仍继续扛门并把何卫东从闸边救回；第005章陈勇留下组织出口、接应何卫东，把追车交给沈辞。两人完成阶段分流，行动信任保留。
- 沈辞 / 程越 / 许晴：方案A旧关系，已从现行第001-010章撤下，不作当前连续性依据。
- 沈辞 / 林照：第005章由林照卡车救治男孩与知微起步。沈辞只指出交接牌被墨覆盖的位置，林照亲手擦出血指印，再以脉搏、瞳孔、氧流和出血独立复核；她因病人仍需持续救治主动随车。两人的关系起点是“现实证据与异常读法互相校验”，不是无条件信任。
- 沈辞 / 沈知微：第006章知微隔床制止哥哥呼名，并在路线错乱时连续三次踢落隔离栏；沈辞越过栏杆后没有立刻动她腕上的红色`17`。兄妹关系从隔着流程互留退路推进到近身重逢，但下一步救法必须尊重知微的判断。
- 沈辞 / 林照：第006章沈辞被右耳假敲击诱导，险些拉错床锁；林照直接按住他的手，用呼吸、床栏震动和氧气管变化完成纠错。沈辞主动锁回床扣，两人的有限协作落成`异常线索可报，实际动作须经现实痕迹复核`。
- 沈辞 / 沈知微：第007章沈辞明明已经碰到妹妹，却在剪带伤及男孩、强推数字再次转移后主动停手；知微提出追接床者，亲手扣回束缚带并把哥哥推出白车。兄妹关系从“互相留路”推进为真正承认对方有权决定救援顺序，目标一致但不再由沈辞单方面作主。
- 沈辞 / 林照：第007章林照用面罩雾气、指温和腕痕变化再次否决沈辞的越界动作；沈辞服从止损。她随后因`随车医护`栏补名被迫离车，两人的下一段同行建立在更明确的分工上：异常找路，医学事实决定行动。
- 沈辞 / 沈知微：第008章登记册里的`沈`字继续退空，沈辞没有回头盲追白车，而是保下第三组残页，真正按知微留下的“追接床者”判断行动。兄妹协作从尊重救援顺序推进为隔线执行对方方案。
- 沈辞 / 林照：第008章沈辞主动报告错听，林照用登记记录、完整批号、封口与安瓿实触落锤；沈辞接受缺失信息不补、假声不追，并先送药后上高架。两人的临时制动关系推进为可执行的现场分工。
- 沈辞 / 沈知微：第009章沈辞追白车跑出三步后，被袖口松线带回知微第007章“别只看我”的要求，最终折返救下老许；随后又从老许口中确认知微右手带血、仍清醒敲栏且进门时还在骂人。兄妹协作从执行接床路线推进为知微缺席时仍能改变哥哥的救援选择。
- 沈辞 / 林照：第009章林照在天桥救援中会判断失误、重做系点和回头扣，也在桥体错位时明确承担割绳止损；沈辞服从边界，却没有把决定全推给她。两人的关系从现实复核分工推进为共同救人、共同承担救不了第二次的高压搭档。
- 沈辞 / 林照：第010章两人把左肩两下定为不受门内假声干扰的实触确认；林照先承认接床误判，再拆穿沈辞把`17`说成知微的借口，迫使他承认分不清并主动停下。关系从现场分工推进到能逼对方说出真实动机、也能服从对方止损。

## 沈辞 / 林照感情线确认

- 路线已固定为克制但明确的慢热感情，不改成纯战友，也不在卷02突然进入恋爱状态。
- 第115章是允许出现私人变化的起点。卷02需要从大量`医疗托底 / 守边界`中筛出少量真正改变关系的场面：隐瞒伤势引发争执、林照拒绝把沈辞当异常工具、沈辞尊重她独立救人判断、其中一人为另一人承担可见后果。
- 卷03至少完成两件事：一次立场冲突不能立即靠规则答案消解；一次私人选择必须付出路线、伤势、资格或信任代价。到卷末，读者应当不需要旁白说明就能确认两人的感情。
- 卷04前后完成互相确认。确认要用人物自己的普通话和行动完成，不用濒死告白、强行接吻或规则替人物宣布关系。
- 卷05以后两人是稳定伴侣与共同责任人，但仍可在救谁、撤不撤、谁承担代价上发生冲突；感情成立不等于意见永远一致。

## 沈辞 / 沈知微终局关系确认

- 沈辞最终面对的不是怎样把知微修复成灾前原样，而是能否承认带着`17号`灰痕、记忆缺页和异常感知的她仍然是沈知微。
- 卷04知微主动进入失名深层时，兄妹冲突要落在`保护是否等于替她决定`。沈辞可以反对、害怕和失败，但不能把她重新压回没有选择权的保护对象。
- 卷07知微依靠自己的判断归来，不由沈辞单方面召回或命名创造；卷08兄妹关系正常成立，她也保留拒绝追听未归名字、拒绝再次救人的权利。

## 沈辞 / 沈父终局关系确认

- 沈父终局活下来承担审理，不用死亡或融入规则换取父子和解。沈辞拒绝父亲方法的立场不会因完整真相揭开而消失。
- 沈父必须亲自对受害者和家属说出自己批准过什么、知道会失去谁、当时为什么仍然签字；不能只向沈辞解释`为了更多人`。
- 沈辞可以在归名工作中与他有限合作，也可以承认他仍是父亲，但无权代表受害者原谅。两人的结局是保留关系与责任裂口，不恢复成普通家庭。

## 灯港共同治理关系确认

- 沈辞不是林照、杜衡或居民代表的上级。林照独立决定医疗救援与公共卫生，杜衡负责封控和路线安全，居民议事处理共同生活，归名记录席保存损痕、反对意见与责任。
- 沈辞只守不可逆规则边界。他可以否决永久改名、身份牺牲和剥夺归还资格，但不能越过当事人指定谁应留下、谁应离开或资源给谁。
- 卷05以后人物冲突不靠下属反抗领导制造，而靠职责真实冲突：医疗要先救谁、城防是否封区、居民是否愿意留下、规则边界能否接受多数人牺牲少数。

## 卷01收束关系补记

- 沈辞 / 沈知微：第113-120章从“不可替换”推进到“隔着边界互相留命”。知微以半称前痕主动轻应，沈辞用她争来的三息读门；第119章她滑位后自己压回源位，第120章沈辞停下第三次敲门，只等到她抓住毯角。兄妹仍未恢复日常，完整姓名与完整亲称暂不可碰。
- 沈辞 / 林照：第116章林照用只报物不报人名的方式帮沈辞抵住门反读；第119章她用脚部温度确认蓝鞋孩子仍活着，又阻止沈辞用麻木右手够读口；第120章连续挡下新腕带、第三次敲门和右手指印，并要求知微不随证转移。关系推进到林照主动替沈辞守身体与关系边界。
- 沈辞 / 杜衡：第118章杜衡接受沈辞最终旧边名；第119章听见门后哭声后执行半寸留缝并署责；第120章递出临时证、准许左手按印，又书面排除知微随证转移。关系从封门互用转为有明确责任边界的`监管借用`。
- 沈辞 / 顾焰：第113章替换方案被规则否决，第117章黑箱记录近似改名不可复现；第119章顾焰继续测量缝底并得到`HL-02`，第120章复核标记只停在医疗帐外。关系仍是财团持续观察与解释权争夺，顾焰没有取得医疗和证件核心处置权。
- 沈辞 / 城防局：卷尾正式从临时协查升级为`监管借用`，沈辞被纳入体系但不是自由入职，也不是完全信任。

## 卷02开篇关系补记

- 沈辞 / 城防局：第121章临时证正面入档；沈辞越过黄线扶蓝鞋孩子时，证绳直接把他勒回，监管从证件文字变成身体边界。杜衡保留紧急联系人空白并署责执行。

## 使用规则

1. 关系变化必须写清楚“因为什么变”。
2. 如果关系变了，但没有事件支撑，那就是写飘了。
3. 感情线推进必须和共同经历绑定，不能凭空升温。
