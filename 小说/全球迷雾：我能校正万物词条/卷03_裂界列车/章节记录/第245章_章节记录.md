# 第245章：第一批适格对象不得默认全城

## 1. 本章定位

- 所属卷：卷03 裂界列车
- 所属阶段：阶段01 / 裂界实核与迁徙口
- 章节功能：承接第244章章末适格对象提交要求，阻止外部用全员默认把所有缺项活人一次性筛成未适格
- POV人物：沈辞
- POV类型：第三人称贴近沈辞
- 时间：D3 03:45-03:50
- 本章开始时间：D3 03:45
- 本章结束时间：D3 03:50
- 时间跨度：约5分钟
- 与上一章间隔：无
- 地点：安置区总表边屏 / 第一批适格表 / 安置区边线 / 17号白床医疗远线 / 待核边线 / 城防值守端 / 财团旁读端
- 目标字数：2000-2200字（可上浮至2300字，不能低于2000字）
- 实际字数：2138
## 2. 本章目标

- 本章要推进的主线层级：迁徙适格名单与谁能走的生死选择
- 本章核心冲突：适格表要求提交第一批对象，并用默认全员和未适格灰框逼现场立刻分人
- 这章结束后局面具体变化：第一批适格对象不默认全城，未适格灰框暂不落人，迁徙口预成立并转入分离未适格边
- 这章会让读者对谁产生新的认知：迁徙不是全城获救，而是会筛人、分人、逼人争位置
- 本章必须交代的信息：默认全员不是安全，它会让所有缺项一起接受同批核验并被同时筛掉
- 本章新增物品/能力/规则/伏笔：新增规则`第一批适格对象不默认全城 / 未适格暂不落人`
- 本章结尾钩子：`迁徙口预成立 / 请分离未适格边`
- 本章风格目标：用脚边灰框、幸存者质问、白床不入批次和待核者按旧物制造生死筛选压力
- 本章对应卷目标：正式把第246-260章的核心推进到“谁能走、谁不能走、如何不让活人被提前排除”

## 3. 本章剧情梳理

- 开场状态：总表要求提交第一批迁徙适格对象，并默认对象为安置区全员
- 事件一：沈辞判断全员默认会触发同批核验，把幸存者、待核者、知微、值守和边线协助一起送入同一套筛选
- 事件二：人群质疑“不默认就是放弃”，总表把`未适格`灰框落到幸存者脚边并跟随退步
- 事件三：沈辞拒绝按人群默认，改按已实核边界，但因已实核边界不足而让第一批对象暂不生成
- 结尾结果：未适格灰框暂不落人，迁徙口预成立并要求分离未适格边
