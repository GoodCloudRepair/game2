# 第242章 延误责任不写现场值守

灰表顶出来时，杜衡的手指还压在封条上。

`迁徙延误责任：请提交`

签位空着。

空得很规整。

像早就等好了名字。
灰表下沿还压着一条细白折线，折线正对杜衡按封条的手，像表纸已经替他的手留好了落章位置。

杜衡没有去碰笔。

他先看值守端。

红灯仍在手动低限线上，灯色比刚才更薄，像一层快烧完的灰纸。

沈辞看见那张责任表下面还有三条极浅的引线。

一条连向城防值守端。

一条连向他的临时证缺角。

最后一条绕过医疗外线，擦向安置区总表边缘的城防编号。

不是问谁能走。

是先问谁害他们没走。

顾焰的蓝点这次没有急着插话。

他被上一章的旁注抢过一次解释权，声音比平时更冷。

“它开始倒置责任。”

“外部迁徙口最忌讳空延误。”

“没有结果，就一定要有人承担未结果。”

杜衡低声道：“城防不提交。”

总表边屏立刻回推。

`未提交视为现场值守延误`

红灯闪了一下。

下一秒，城防值守端直接黑屏。

只黑了三秒。

可这三秒里，安置区边线像被抽掉一根钉子。

半圈手动封条轻轻一松。

被压在封条内侧的旧布包往外滑了半寸。

抱着布包的女人脸色煞白，手也跟着滑开。

沈辞没有喊她名字。

他甚至还不知道她完整的名字。

他只说：“按回原位。”

女人猛地回神，两只手重新压住布包旧结。

布包外侧那片旧灰影刚浮起来，就被她手背压回去。

断鞋带的男人也下意识把脚收住。

旧袖章的男人更快，直接用肘弯压住袖口。

三个人都没出声。

他们已经知道有些反应不能给。

红灯在第三秒末重新亮起。

杜衡额角的青筋跳了一下。

“手动端短断。”

他声音很沉。

“记录，非人为离岗。”

可短断留下的空白已经落在封条上。

半圈灰色封条多出三枚针孔状的焦点。

每一枚焦点下方，都浮着极淡的时间。

`三秒`

`三秒`

`三秒`

它们像在提醒所有人，刚才确实有一小段无人值守。

旁边一名城防执行员本能地抬手，想去按备用端。

杜衡没看他，只低声说：“别补。”

执行员的手停在半空。

备用端已经亮出一行浅字。

`空缺值守可由备用端继承`

沈辞立刻说：“继承就是承认空缺。”

那名执行员脸色发白，硬生生把手收回来。

备用端的浅字暗下去，却在表角留下一个灰点。

责任表又多了一条可咬的边。

灰表立刻贴上一行。

`短断期间边线松动`

`责任可归值守端`

杜衡的嘴角绷得更紧。

灰表没有骂人。

它把事实切成可承担项。

只要写了“值守端短断”，后面就能写“值守不稳”。

只要写了“值守不稳”，未迁徙就能被归到现场。

沈辞抬手按住临时证。

缺角热得发钝。

他能感觉到责任表正在等他接第二条线。

`边线协助人可代提交原因`

顾焰终于开口：“如果你不写，它会继续压杜衡。”

“写了就压我。”

沈辞说。

顾焰没有否认。

林照的纸带在远线处轻响。

“别接。”

她说得很短。

“延误责任不是医疗项。”

责任表像听见了她的话，立刻往医疗外线贴去。

`医疗拒绝协助迁徙，是否构成延误`

林照那边传来金属托盘被按住的声音。

“救治不是迁徙。”

纸带压住那行字。

`17号白床未醒`

`体征低位`

`不参与责任判定`

灰表没有退。

它换了方向，重新贴回城防值守端。

`现场多次拒绝：活城回问 / 记录复写 / 医疗旁签 / 旧痕合项 / 父线补项`

五条拒绝被排成一串。

看上去像证据。

安置区人群里，有人喉咙里发出很轻的抽气声。

这串字太容易被误读。

他们看不懂为什么不能填。

只看见一次又一次拒绝。

沈辞看着那串字，没有解释。

解释会变成旁注。

旁注刚刚才被压回外来层。

他必须把责任表切回原本的问题。

问题不在谁拖延。

是外部实核还没给出合法对象、合法记录和合法边界。
那五条拒绝在灰表上排得很齐，像五根指头，一根一根按向杜衡、医疗外线和沈辞临时证。只要其中一根按出血印，空签位就会有名字。

沈辞走近半步。

监测半径线在脚下轻轻发冷，提醒他不能再往前。

他停在边内。

“写原因空项。”

杜衡看向他。

沈辞说：“不写责任人。”

杜衡立刻敲字。

`延误责任：不归现场值守`

总表回推。

`无责任人，延误不成立`

沈辞盯着那行字。

“不成立就不成立。”

顾焰冷声道：“外部会按规避处理。”

“那也比错写责任人好。”

沈辞说。

责任表边缘猛地收紧。

城防值守端红灯又暗了一下，这一次没有黑屏，却把杜衡手下的封条烫出一小截灰白。

杜衡没有松手。

皮肤和封条接触的位置冒出一点焦味。

他只把声音压得更低。

“继续。”

封条下方的旧胶开始发皱。

那不是普通受热。

每一道皱痕都像在替责任表找一个可落笔的手印。

杜衡的手背被烫得轻轻一颤。

总表马上亮起。

`值守人身体反应：可作承压证明`

沈辞没有让这行字长大。

“身体反应不作责任证明。”

林照在远线补得更快。

`烫伤记录：医疗止损，不作延误归因`

沈辞看着那一点焦灰。

左眼暗区开始往内压。

他不能让杜衡替所有未完成项背责任。

也不能自己接。

更不能让医疗和待核者接。

他把临时证缺角对准责任表下沿。

不是补。

只是让缺角贴近那条引线。

“原因不完整。”

他说。

“实核未完成。”

`未完成可追责`

“追缺项。”

沈辞一字一顿。

“不追现场人。”

杜衡敲下同样的字。

`实核未完成：追缺项，不追现场值守`

灰表卡住。

它想把“缺项”改成“缺人”。

沈辞提前按住临时证，缺角边缘烧得他指腹发麻。

“缺项不是缺人。”

值守端红灯重新稳在低限。

手动封条那一寸松动被杜衡压回去。

三名待核者的旧痕也重新贴回各自边线。

责任表上的空白签位一点点灰下去。

最后只剩一行冷字。

`迁徙延误责任：暂不提交`

安置区没有人松气。

因为总表最外圈忽然响了一下。

像一枚印章倒扣在旧纸背面。

黑色戳痕从边屏外侧退回来，重重压在`海陵旧边`四个字旁。

`外部退回：本城旧边不可识别`
