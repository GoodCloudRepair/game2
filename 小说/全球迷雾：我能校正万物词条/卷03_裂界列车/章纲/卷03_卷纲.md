# 卷03_卷纲：裂界列车

## 一、卷级定位

- 卷名：裂界列车
- 规划长度：80-90章，约17-19万字
- 起始章：第236章
- 起始时间：D3 03:00后
- 起始地点：安置区总表边屏 / 裂界列车实核黑格 / 灰门监测缝记录 / 临时证 / 医疗远线 / 待核边线 / 财团旁读端
- 卷级主轴：完成迁徙，扩地图，第一次确认灰雾不是随机灾难，而是文明筛选与归档流程的一环。
- 当前状态：第236-260章已完成，仍在安置区总表边屏实核层，尚未登车；第261章承接`第一批接入条件：本人边 / 独立承压事实 / 活项未裁`。

## 二、卷级核心任务

1. 把卷02留下的`裂界列车实核：待后续`正式接入，不倒回补门、不补站台、不补出城口。
2. 让外部实核先变成压力：反查海陵是否仍活、谁可被识别、谁不能迁出、哪些空项会杀人。
3. 第246-260章把“谁能走”写成生死选择，车影和远灯可逐步显露，但不可提前登车。
4. 第261-266章在同一场持续冲突中交叉核验三项接入条件，不按一项一章拆成核表；第267-269章形成首批名单并走到真实登车口，第270章完成正式登车，让第一条车内规则当场产生后果。
5. 卷03中后段完成第一次正式、有限的改名：最早第281章以后，必须由沈辞独立完成局部校正，不靠知微替稳，并留下不可恢复的长期代价。
6. 落下一条编目师来源硬证据：候选痕会随沈辞保留具体人、拒绝完整模板和承担判断后果而变化，却不响应血统、职级或财团权限；只证明筛选看选择，不揭沈父具体干预。
7. 推进顾焰替换样本线：财团设备开始把顾焰本人作为稳定参照，并至少一次越过他的明确意愿调用身体、声音或权限；只写异常和他的失控反应，不在卷03揭`完整替换样本`结论。
8. 卷尾揭开一层真相：灰雾与裂界列车同属文明筛选/归档流程的一环，但不提前解释编目庭本体。

## 四、开篇十章节奏原则

- 第236-245章不写站台、不登车、不写完整路线。
- 每章必须有现场后果，不能只核表。
- 表现方式轮换：回问、复写、旁签、点名/抽检、缺项逼补、责任倒置、旧痕移位、外部退回、局部处罚、远灯预压。
- 沈辞仍靠观察和压窄定义推进，不用稳定改名，不生成面板或能力说明。
- 顾焰继续是压力源，不可靠救场；林照以救人和迁徙安全为独立目标，不再只重复守医疗边界，她会在沈辞继续承压还是先止损的问题上与他发生一次真正冲突，并用一次有代价的私人选择推进关系；杜衡只做限权执行。

## 五、卷三前段硬禁

- 不倒回卷02补开门、路线、站台、车门或出城口。
- 第236-280章不让沈辞正式掌握改名，不写训练样本、技能说明或可复用招式；第281章以后即使正式成立，也只允许有条件的有限校正。
- 不让沈知微醒来、完整认亲、康复、作锚或解释规则。
- 不确认三名待核者整名，不让旧痕合袋、上传或成为迁出样本。
- 不揭父亲完整签码、项目名、目的、立场或编目庭真相。
- 不把`编目师候选`写成自动授能、血统认证或父亲预设的继承位。
