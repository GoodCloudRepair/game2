# 卷03_阶段01_236-260章大纲：裂界实核与迁徙口

## 阶段定位

- 时间：D3 03:00后至D3清晨
- 地点：安置区总表边屏、实核黑格、灰门监测缝记录、医疗远线、待核边线、临时封存车、城防值守端、财团旁读端；后段可逐步出现外部远灯、轨声、车影，但第260章前不登车。
- 阶段目标：让裂界列车先成为外部实核压力，再成为迁徙生死选择。
- 当前执行：第236-240章已完成实核开篇五章，外部承认再下调，下一步转入`迁徙适格 / 谁能走`。

## 阶段推进

| 小段 | 章次 | 功能 |
| --- | --- | --- |
| 236-245 | 实核无站台 | 外部实核反查卷02预口、空项和承认缺失；每章有现场代价 |
| 246-250 | 迁徙口预成立 | 海陵需要迁徙，但所有人不是默认可走，旧痕和身份缺口开始影响资格 |
| 251-255 | 谁能走 | 选择压力压到沈辞、知微、三名待核者、林照、杜衡和安置区幸存者 |
| 256-260 | 谁不能走 | 远灯/轨声/车影形成可见倒计时，但站台和车门仍不完整；第261-266章先在持续冲突中核三项接入条件，第270章正式登车 |

## 236-245防腻要求

- 不能章章写“空格问某项”。
- 轮换表现为：回问、复写、旁签、点名/抽检、缺项逼补、责任倒置、旧痕移位、外部退回、局部处罚、远灯预压。
- 每章至少出现一个可见后果：证件发热、封条渗灰、波形下坠、旧痕错位、页脚逼补、值守端掉线、边线收窄、外部退回黑戳、灰灯压眼、远灯压屏。
- 每章只给一条关键新信息，避免把卷三开头写成说明书。

## 阶段边界

- 实核可以确认外部确实在找海陵，但不能确认完整站台、车门、路线。
- 第240章父线只作危险证物，不作答案；旧页脚差一点补上，立刻压住。
- 第246-260章重点不是“登车手续”，而是让读者看见不迁徙会死、乱迁徙也会死。
- 第261-266章在同一场持续冲突中交叉核验`本人边 / 独立承压事实 / 活项未裁`，不得按一项一章写成核表；第267-269章形成首批名单并抵达真实登车口，第270章正式登车。
