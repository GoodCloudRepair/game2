# 《全球迷雾：我能校正万物词条》写作风格约束

## 一、总风格定位

本书的核心风格为：

- 冷峻
- 克制
- 悬疑
- 压迫
- 精准
- 电影感
- 强钩子

可以理解为：

`末世悬疑气质` + `商业向连载节奏` + `规则系主角视角`

这意味着本书既不能写成纯热血中二升级文，也不能写成过分缓慢的文艺散文化叙述。

## 二、基调约束

整体气氛应当偏冷、偏紧、偏危险。

读者进入这本书后，应该持续感受到三件事：

1. 世界是坏掉的，而且正在继续坏下去
2. 规则不是背景板，而是真正会杀人的东西
3. 沈辞不是最强的人，但往往是最先看清问题的人

不要把末世写得太轻松，也不要把危险写成纯装饰。

## 三、叙事视角约束

### 1. 以沈辞感知为核心

正文默认贴近沈辞的观察与判断展开。

他的视角重点不在于激情宣泄，而在于：

- 看到异常
- 判断异常
- 推演危险
- 在有限信息中做出选择

### 2. 少做上帝视角解释

不要频繁跳出场景，直接替读者总结世界观。  
世界信息更适合通过这些方式自然露出：

- 环境细节
- 怪物行为
- 广播或警报
- 墙面文字
- 幸存者反应
- 遗物词条
- 门域规则

### 3. 情绪表达要压着写

沈辞可以痛、怕、怒、愧疚，但不适合长期外放式表达。  
更适合的写法是：

- 先动作
- 再细节
- 最后给一点情绪裂口

这样更符合人物气质，也更有力量。

### 4. 禁止台账式回指

正文叙述中不得以章节编号作为事件锚点回指前文，包括但不限于：

- `第X章` `上一章` `前一章` `本章` `上回`

所有回指必须使用故事内部锚点：
- 空间位置：`二层` `旧名室` `签字口前` `回认台前`
- 物件名称：`灰盒` `旧借图` `旧借册`
- 人物名：`杜衡那次` `老太婆说完那句话之后`
- 事件名：`无名区那次` `回听格那一段` `广播楼那次`

这一条也覆盖 `00_`「解释永远晚于现象」原则——用"同一次/那一段/前面"等内部时间锚点替代台账编号，保持沈辞视距内的叙述统一。

## 四、语言风格约束

### 1. 句子要干净

优先使用清楚、直接、有效的句子。  
少写空泛形容，少写重复修辞，少写无意义的感叹。

推荐写法：

- 一个异常细节
- 一个即时判断
- 一个动作反应
- 一个后果变化

### 2. 抒情必须节制

不能整章停下来抒情。  
如果要写情绪或氛围，应当依附在具体场景之上。

例如优先写：

- 血
- 雾
- 灯光
- 尸体
- 楼道回声
- 失真的广播

而不是大段抽象感慨。

### 3. 保持画面感

每一章最好都有可以“看见”的东西。  
读者读完后，脑中应该能留下场景，而不只是概念。

## 五、节奏约束

### 1. 单章节奏

每章不少于2000字，软目标2000-2200字；允许因人物状态、情绪转折、关键动作等需要上浮约100字，最高尽量不超过2300字。尽量遵守以下结构：

1. 开头10%-15%给出场景状态或异常钩子
2. 中段60%-70%推进冲突、行动、判断或信息变化
3. 结尾15%-20%给出反转、发现、危机或下一章钩子

### 2. 单章不要做太多事

一章里通常只做三件关键事中的两件：

- 推剧情
- 揭示新信息
- 推关系变化

不要在一章里同时塞满：

- 世界观大段说明
- 大战斗
- 长回忆
- 多角色对话局

否则会散。

### 3. 句号即换行

正文叙述段落中，每个句号必须换行。两个句号不得出现在同一行内。

- 引号内对话的句号不受此限制，允许对话中的多句保持在同一段。
- 连动动作（句号前后为同一人物的连续身体反应、视线移动或现场后果）可用逗号衔接；一旦以句号收束，下一句必须换行。
- 逗号分隔的多个动作或观察点可以保持在同一段内。

这条规则的目的不是把正文切成碎句，而是保证手机端每行只承载一个可独立阅读的完整语义单元。

### 4. 手机端段落长度

番茄用户以手机碎片化阅读为主，段落过长会直接降低阅读舒适度。

- 手机端清晰是目标，不以越短越好
- 单段常规控制在`20-80字`
- 超过`100字`先检查是否能拆
- 超过`120字`原则上必须拆
- 超过`160字`视为风险段，只在极少数强压迫场景保留
- 连续短段过多时，优先合并成中段现场描写；单独节拍句只用于强停顿、异常感或情绪断裂
- 心理、规则、场景长描写优先拆成“动作 / 反应 / 后果”三段
- 对话前后的动作反应可以拆开，但同一发言意图内优先保留完整段落，避免碎成台词日志
- 句号后如果切换声音来源、人物动作、视线落点、物件反应或危险反馈，可以换段；若仍属于同一现场后果链，优先合并成不压屏的自然中段
- 正文中要穿插中段现场段，用来承载空间、身体反应或人物误解，避免全章碎成短鼓点
- 规则代码块前后优先补可见身体/物件后果，避免形成“规则条 → 短反应 → 规则条”的日志结构

### 5. 剧情功能优先于段落指标

段落密度、短句比例只作预警，不作机械判定。判断一章是否需要精修，优先看短句是否服务剧情功能：

- 指挥口令、诱惑静压、规则警报、濒死反应可以保留短句节奏。
- 如果短句只是连续解释规则、重复判断、罗列术语，则需要改成现场后果链。
- 精修优先级不是“短句最多的章”，而是“读者读完只记住规则、记不住人和现场”的章。
- 每次改文先判断本章功能：铺垫、反转、情绪核、规则验证、动作战线，不同功能允许不同节奏。
- 不为降低短句比例牺牲压迫节奏；不为保留压迫节奏放任说明书口吻。

一句话：先判断短句有没有在干活，再决定要不要合并。

### 6. 规则验证章写法顺序

规则验证章要先让某个替代方案或错误理解撞到现场，再让身体、物件、外线或读口出现后果，最后才给规则判词。禁止先把规则原理讲完，再补一个结果。

## 六、对白约束

### 1. 对白要带功能

本书对白主要承担这些任务：

- 交换信息
- 暴露立场
- 推动冲突
- 建立关系张力

禁止大量无功能闲聊。

### 2. 角色说话要分得开

沈辞说话应当：

- 少
- 准
- 冷静
- 不废话

林照说话应当：

- 现实
- 直接
- 有执行压力

顾焰说话应当：

- 锋利
- 带压迫感
- 有优越感但不油腻

其他反复出现的配角也要有稳定声线：

- 程越：嘴硬调皮，怕也先顶一句，用轻佻遮住发抖。
- 许晴：冷静观察，先给事实和细节，不急着解释情绪。
- 陈勇：保安经验，说门、钥匙、通道、监控，判断更接地气。
- 抱孩子女人：护崽优先，语气现实，必要时会谈条件。
- 普通路人：允许粗糙、慌乱、抱怨、重复、错话，不能都像规则研究员。

写对话前先判断人物此刻的压力反应：急了是更快、更碎、更凶，还是更安静、更流程化。声线来自身份和处境，不靠口头禅硬贴。

人物状态要跟着场景压力变化。重要配角开口前后，优先用一两个动作或注意力落点区分人：程越先遮怕，许晴先看细节，陈勇先摸门路和钥匙，林照先确认呼吸、药量、出血点。少写“他很冷静/她很害怕”，多写身体反应和处理顺序。

### 3. 人物失态差异

不要让所有人都默认镇定、懂规则、会配合。

除沈辞、林照、杜衡、顾焰这类长期承压或专业角色外，普通人第一次撞规则时，优先写误解、乱动、错话或本能反应，再写规则后果。恐惧不能只写成脸白、指节收紧、呼吸顿住，要允许它变脏、变乱、变粗糙。

不同人物的失控方式要分开：

- 学生：小声互相提醒、写错后拼命擦、哭到不敢出声、想躲到同学后面。
- 家属：不讲规则，只讲“我就看一眼”“他是我儿子”“我不叫名还不行吗”。
- 城防新人：手快、怕担责、想按流程补栏，越急越容易补错。
- 老执行员：表面镇定但麻木，说话像加班，先保流程不保感受。
- 普通幸存者：抱怨、反复问废话、突然抢东西、想先挤进安全栏。
- 林照：镇定来自职业反应，急在手上，先看出血点、药量、针压。
- 顾焰：镇定来自距离和利益，他越稳越危险。

规则验证时，普通人如果只负责“正确地害怕”，就会变成演示样本。每个失态动作都要带一个活人目的：想救人、想确认、想逃、想抢先活下来、想把旧物拿回来。

### 4. 少写网文化嘴炮

可以有反击和锋芒，但不要把人物写成一直抖机灵。  
这本书更适合“压着说一句狠话”，而不是连续段子式输出。

## 七、战斗与规则描写约束

### 1. 战斗重点不是炫招

战斗描写应优先突出：

- 局势判断
- 危险来源
- 规则识别
- 代价交换
- 逆转节点

不是单纯拼谁吼得响、招式名更夸张。

### 2. 规则要能影响战斗

沈辞的优势来自“看懂”和“改动”。  
因此战斗里必须体现：

- 他发现了什么
- 他利用了什么规则
- 他付出了什么代价
- 局面为什么因此改变

### 3. 危险感不能丢

哪怕主角赢了，也不应总是赢得轻松。  
每次胜利最好都伴随其中一种结果：

- 消耗
- 受伤
- 暴露
- 误判
- 更大的麻烦

## 八、悬念与信息投放约束

### 1. 解释永远晚于现象

先让读者看到异常，再慢慢知道原因。  
不要一上来把所有逻辑讲明白。

### 2. 每章至少留一个未完全解释的点

这个点可以是：

- 一个不合理现象
- 一个词条异常
- 一个身份疑点
- 一句含义不明的话
- 一个未来威胁

### 3. 真相要分层给

不要一次讲透。  
更合适的方式是：

- 先给现象
- 再给误导解释
- 再给部分真相
- 最后才给完整答案

## 九、人物情感约束

### 1. 情感要长出来，不要突然写满

关系推进必须依托共同经历、救援、误解、牺牲、并肩承担。  
不能因为“设定上是男女主”就突然升温。

### 2. 兄妹线要克制但有重量

沈辞和沈知微的关系不是口头式“我一定保护你”，而是：

- 明知危险还会回头
- 明知代价还会选择承担
- 在冷静外壳下暴露真正软肋

### 3. 情绪爆点要少而准

平时克制，关键时刻才炸开。  
这样情感峰值才有冲击力。

## 十、章节结尾约束

每章结尾最好满足以下至少一种：

- 发现新的异常
- 看见更大的危险
- 关系突然变化
- 关键人物说出反常信息
- 规则被改写
- 主角意识到自己判断错了

结尾要让读者自然产生“再看一章”的冲动。

不推荐把章节结尾写成：

- 单纯总结
- 纯抒情停顿
- 无变化地结束场景

## 十一、抓力三刀法（反描述化软规则）

> 核心标准：**先让读者看见人被咬，再让沈辞动手，最后才允许半句规则。**
> 这三条是软规则，不是硬清单；硬清单会把正文写成表格，这三条用来挤掉翻译腔和演示味。

### 1. 反翻译腔写法

**硬原则：规则不翻译。**

规则怪谈的核心魅力来自留白、猜测、自行推理、信息差恐惧。一旦作者在规则出现后立刻追加解读——就像外文丢出来马上紧跟着译文——悬念直接消失。

- **只放出原始规则**（告示原文、广播原句、观察板显示、流程原话）
- **不以旁白翻译规则**（不写"主角很清楚……""这说明规则要的是……""一旦……就会……"）
- **以行动推理**：主角通过碰壁、观察、试错慢慢摸索规律，读者跟主角同步推导
- **让身体/物件替规则开口**：先写人被咬、物件咬、流程反咬，再给沈辞半句判断

#### 禁用句式清单

尽量少用：

- `说明……`
- `这不是……而是……`
- `原来……`
- `它要的不是……`
- `这意味着……`
- `更像是……`

推荐顺序：

1. 先写身体反应（手抖、喉紧、鞋尖挪、指腹被纸边割一下）
2. 再写物件反应（夹子咬、灯丝亮、旧证发热、纸角自己翘）
3. 最后才允许一句判断

反例：`这不是点名册，而是一把卡住后字的锁。`
正例：`女老师红笔落下后，17桌角那只白夹往里咬了半寸。沈辞没再看第二格。`

### 2. 反演示味写法

路人不能只为演示规则存在。每个“路人”至少要有一个活人目标：想帮忙、想确认自己是谁、想杀人、想活命、想把东西抢回去、想把竞争对手除掉。

不要连续用多个路人演示同一条规则。规则一旦出现，立刻并入沈辞动作链：

`路人本能动作 → 规则咬身体/物件 → 沈辞借机改位/压退/撤离 → 结果变化`

### 3. 章末钩子刀法

章末不要解释下一步，只让一刀落下。

章末尽量别写：

- 用规则逻辑总结本章
- 用沈辞内心独白总结危险
- 用“这说明后面还有更深流程……”收尾

章末优先写：

- 一个动作被门口截住
- 一个旧物被抽走
- 一个人被迫松手
- 一个隐藏字角露出半截
- 一个称呼差点脱口
- 一个声音、一道光、一只手先于人出现

## 十二、降低AI感与模板感专项约束

> 目标是消除读者能直接感到的机械感，不是追逐检测器百分比。检测结果只作预警；不得靠病句、错字、断裂因果或故意制造混乱来“降AI”。

### 1. 分级处理连接词与解释句

- 正文旁白硬禁`综上所述 / 值得一提 / 由此可见 / 换言之 / 显而易见 / 对于……而言 / 在……层面上 / 以一种……方式 / 这使得 / 进行着 / 拥有着`等总结性书面腔和翻译腔，非豁免命中必须清零。
- 正文旁白不得用`不是A，而是B / 不是A，是B / 没有A，而是B / 并非A，而是B / 是A，也是B / 既是A，也是B`等成对判断句替作者翻转、补充或重新定义。需要表达时，改写为可见动作、物件变化、身体反馈或直接结果。
- `然而 / 因此 / 终于 / 与此同时 / 下一瞬 / 这一刻`属于转场预警词；`明白了 / 意识到 / 这说明 / 这意味着 / 也就是说 / 原来 / 更像是`属于解释预警词。命中后逐处判断是否有真实时间或推理作用，不作机械清零。
- 同一个转场预警词在一章内出现`2次`以上时，全部进入重点复核；只保留确有时间推进作用的命中，其余优先用人物动作、声音切换或物件变化承接。
- 旁白中的结论式解释模板全章合计原则上最多保留`1处`。广播、告示、规则原文和人物对白若符合信息来源与人物声线，可以登记豁免；人物说出本可由作者总结的完整规则答案，不得豁免。
- 不得把同一信息连续写成“发现异常 → 解释异常 → 再总结结论”。三步里最多保留两步，优先保留现场与行动。
- 不得为了避开词表，机械替换成`可 / 却 / 于是 / 显然 / 只有 / 与其`等近似结构；判断标准始终是这句话是否真的推动现场。

### 2. 打破句式和段落的机械整齐

- 同一小段场景内，不连续使用三次同构句式，如连续三个`他看见……`或连续三个`不是……而是……`。
- 除濒死、警报、指挥口令、强停顿等场面外，不连续出现四个以上单句短段。
- 连续三个相近长度的长句、连续三句以同一主语开头，也要进入人工复核；确实服务追逐、压迫或流程碾压时可以保留。
- 常规段落仍按`20-80字`控制，超过`120字`原则上拆段；同时穿插能承载动作、空间和身体反应的自然中段，避免全文变成整齐的“一句一段”。
- 句子允许长短变化和被动作打断，但不能故意写残缺句、病句或含混指代来模拟“人写感”。

### 3. 强化沈辞的主观现场

- 信息尽量通过沈辞此刻看见、听见、碰到、犹豫或决定的东西进入正文，不用脱离其视距的上帝总结替他得出完整答案。
- 推理不必每次闭环。沈辞可以只确认眼前一步、保留误判、晚半拍补齐信息，也可以动作做到一半再根据新后果修正；临场修正必须有可见触发，不能靠作者强行改判。
- 专业信息优先落在旧档修复工作的具体习惯和动作上，但每个场景只留`1-2个`真正影响判断的职业细节，禁止写成知识展示。

### 4. 细节必须参与剧情

- 每个被保留的细节至少承担一项作用：说明危险、空间、人物关系、职业习惯，或直接推动下一动作。
- 使用“不可移植测试”：一处细节若能原样搬到另一个门域或其他章节而不影响意义，就属于泛化细节；删除它，或改成受当前空间、伤势、携带物、规则压力和人物目标限制的现场细节。
- 灰雾与门域可以保留无法解释的模糊感，但至少要落到一个可复述的声音、方位、物件变化或身体后果。留白不能建立在空间断裂和无锚点形容上。
- 只负责“让画面更精致”的衣着、挂件、光影和比喻优先删除，尤其不能在生死场面打断人物的紧迫目标。
- 同一种通用反应，如`心头一沉 / 瞳孔骤缩 / 呼吸一滞`，一章内不重复使用；优先改成会影响动作或发声的具体身体反应。

### 5. 对话保留人的压力反应

- 人物在高压下可以说错、打断、重复、答非所问，不得全员冷静、完整、准确地总结规则。
- 对话必须能看清说话人；制造慌乱不能依靠省略必要的发言归属。
- 人物刚接触规则时，先允许误解、本能动作和错误判断，不能立刻说出作者级结论。

### 6. 结构与章末不做标准答案

- 禁止把一章稳定写成“开头概括问题 → 中段逐项解释 → 结尾再次总结”的总分总结构。
- 场景推进应允许被误判、意外动作、他人私心或规则后果打断，不能每个钩子都按同一间距出现。
- 章末禁止连续三句总结、判断或排比，不总结本章意义，也不替读者拔高主题。
- 章末可以停在未解异常、错名、身份疑点或新规则上，但它必须改变现场局面或下一步选择；禁止只用未知注视、含混危险感或空泛不安充当钩子。
- 优先停在动作未完成、声音闯入、物件变化、人物失手、称呼错位或冷信息落地的瞬间。

### 7. 清晰度高于降AI指标

- 场景位置必须能复述，换场要有空间锚点；不能为追求跳跃感省掉必要路线。
- 对话说话人、人物目标、动作先后和基本因果必须明确。
- 检测器给出的“长句多、连接词多”等结论要先核对正文数据，再决定是否修改，不因单次百分比盲目打乱文本。

### 8. 写后分级扫描与人工复核

每章正文完成后、连续性底审前，只扫描正文文件，不扫描设定、章纲、章节记录、台账或审稿文件。

第一遍扫描旁白硬禁候选：

```powershell
rg -n '综上所述|值得一提|由此可见|换言之|显而易见|对于.{0,30}而言|在.{0,20}层面上|以一种.{0,20}(方式|形式)|这使得|进行着|拥有着|不是.{0,30}(而是|只是|是)|没有.{0,30}而是|并非.{0,30}而是|不在.{0,30}而在|是.{0,30}也是|既是.{0,30}也是' '正文文件.md'
```

第二遍扫描需要人工复核的转场、解释词和模板反应：

```powershell
rg -n '然而|因此|终于|与此同时|下一瞬|这一刻|原来|这说明|这意味着|也就是说|更像是|明白了|意识到|眼神一凝|心(中|头)一沉|倒吸一口凉气|没有丝毫犹豫|嘴角勾起|瞳孔骤缩|呼吸一滞' '正文文件.md'
```

`rg`在零命中时返回退出码`1`，属于正常结果；以没有输出作为零命中判定，不把它当成扫描失败。

- 第一遍每个命中都要区分旁白、人物对白、广播告示和规则原文；旁白中的非豁免命中修到零，对话或原文豁免要确认确实符合人物和来源。
- 第二遍不要求零命中，只删除没有实际时间、推理、声线或动作作用的表达，禁止按词表机械换同义词。
- 扫描完成后人工检查跨句否定转定义、总分总段落、连续同构句、动作后重复解释、脱离沈辞视距的完整答案和可移植细节。
- 额外检查“过度顺滑”：若每段都完整承接、解释、收束，所有人物都按顺序给出准确反应，应让误判、打断、私心或规则后果自然介入；不能为了制造不顺而破坏因果和空间。

## 十三、禁止跑偏的风格

以下写法要尽量避免：

- 太中二的喊招式风
- 太油滑的嘴炮风
- 太抒情的散文化风
- 太硬的设定说明书风
- 太轻松的末世日常风
- 过度玩梗的互联网段子风
- 翻译腔旁白（先解释再给现场）
- 演示味路人串（连续NPC只为讲规则）

`翻译腔`详细禁令见上文**十一·1 反翻译腔写法：规则不翻译 + 禁用句式清单**。

## 十四、每章风格自检

写完一章后，至少自查以下事项：

1. 这一章读起来够不够冷和紧
2. 规则出现后有没有立刻追加旁白翻译/解读（规则不翻译）
3. 有没有出现大段解释压过剧情
4. 沈辞的行为是不是符合观察型主角逻辑
5. 战斗或冲突是不是体现了规则感
6. 结尾有没有留下继续阅读的动力
7. 有没有写成别的题材常见口吻，而不是这本书自己的口吻
8. 有没有先给人/物件被咬的现场，再给半句判断
9. 路人是否带着活人目标，而不是只演示规则
10. 普通人的恐惧是否有误解、乱动、错话或本能目的，而不是全员镇定配合
11. 有没有连续使用同构句式、连续四个以上非必要单句短段
12. 有没有把同一信息写成“发现、解释、总结”三遍
13. 被保留的细节是否参与危险、空间、关系、职业判断或后续动作
14. 降低模板感后，说话人、空间位置、人物目标和因果是否仍然清楚
15. 硬禁候选是否逐处分类，旁白中的非豁免命中是否已经清零
16. 预警词是否逐处人工复核，而非机械替换或盲目清零
17. 是否存在可移植细节、过度顺滑段落或脱离沈辞视距的完整答案

## 十五、风格一句话标准

如果要用一句话判断这一章像不像这本书，应当是：

`在坏掉的世界里，一个更擅长看见规则裂缝的人，冷静地活下去，并一点点逼近更大的真相。`

抓力自检的一句话标准：

`先让读者看见人被咬，再让沈辞动手，最后才允许半句规则。`
