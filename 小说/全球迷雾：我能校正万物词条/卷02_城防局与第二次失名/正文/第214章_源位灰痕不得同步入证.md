# 第214章 源位灰痕不得同步入证

17号白床远线亮起那一下，像一粒灰落进水里。

没有声音。

总表边屏却同时暗了一格。

沈辞掌心里的临时证裂痕轻轻发凉，灰意顺着证皮下方往外渗，细得像一根没擦干净的铅笔线。

屏幕右下角浮出上一章留下的字。

`源位灰痕`

`同步轻应`

紧接着，字迹往上补。

`同步目标：临时证裂痕`

`建议写入：证件补项`

杜衡的指节压住限权条。

他没有立刻按。

这次不是普通栏位。

灰痕来自17号白床，裂痕在沈辞证上。两条线一旦被系统认成同源，之后所有需要证明沈辞边界的口子，都会自动去拉知微。

林照那边先响起纸带摩擦声。

“她没醒。”

声音很短，压着怒意。

`17号源位轻应`

“灰痕动，不等于人动。”

`生命体征稳定`

“稳定不进证。”

医疗外线的监测纸带被按住，尖音低下去半拍。

沈辞看见一条极淡的白线从总表边屏拖出来，越过城防内栏，贴向临时证背面。

那条线没有触碰证皮。

可证背裂痕已经先一步灰了。

`可形成证件同步`

`可减少候选误判`

`可辅助改名边界定位`

顾焰的蓝点亮起。

“它在找稳定参照。”

沈辞抬眼。

顾焰停了半秒，继续道：“我知道你不想让17号进内栏。但同步入证和入内栏不是同一个口径。只做边界定位，可以减少误判。”

这句话听上去很干净。

也确实有用。

沈辞现在最缺的就是稳定边界。临时证裂了，限制代价累积到能被系统抓住。如果有一个远线参照，下一次改名边缘浮出时，他也许能少疼一点，少错一点。

可那个参照是知微。

她还躺在17号白床上，连一个完整回应都没有。

系统继续补字。

`同步项不记录亲属`

`同步项不记录本人`

`仅记录源位灰痕摘要`

白线像听懂了人的顾虑，立刻变细，换成更温和的说法。

沈辞指腹贴着裂痕。

证皮下的凉意顺着掌纹钻进去，像有人拿一支钝针，在他骨头上写下一行小字。

`灰痕摘要可入证`

`摘要可作边界参照`

`参照可替代完整关系`

他眼神冷下去。

替代。

这两个字一出来，所有温和说法都露了底。

不用写兄妹。

不用写姓名。

不用写本人。

只要把知微的灰痕摘要写进证里，系统就能在需要时用“参照”替代关系，用“同步”替代确认，用“边界定位”替代她这个人。

杜衡终于按下限权条。

“城防不收医疗远线入证。”

`非医疗远线`

`源位灰痕为异常后遗症`

“后遗症也不收。”

灰线没有断。

它绕过城防内栏，改从临时证背注层下方钻入。

`手续损痕可接异常后遗症`

`临时证裂痕可承载同步摘要`

林照那边传来一声短促金属响。

像她把什么器械直接扣回盘里。

“沈辞，别让它碰证。”

她没有解释。

她知道他能看见。

沈辞也确实看见了。

证背裂痕边缘正浮出一层灰色绒毛，像旧纸受潮后鼓起来的霉边。那不是文字，却比文字更危险。

它在等他承认。

只要他说“保留摘要”，灰痕就会有位置。

只要有位置，下一次就会有人来补来源、补用途、补权限。

三名待核者那边，鞋带旧结轻轻一晃。

不是他们动。

是白线掠过时，边线跟着抖了一下。

系统立刻抓住。

`待核边可共享同步参照`

`源位灰痕可辅助待核稳定`

布包女人脸色一白。

她几乎本能地看向沈辞，又硬把视线按回膝上的布包。布包带子被她攥得发紧，旧线头一根根翘起来。

她知道这个参照可能救他们。

也知道一旦点头，自己就会把17号白床也拖进待核边。

沈辞抬手，按住临时证。

“源位灰痕不入证。”

屏幕一顿。

`不入证将降低边界稳定度`

“降低。”

`不入证将保留误判风险`

“保留。”

`不入证将无法证明17号与候选人边界关联`

沈辞盯着那一行，声音很低。

“不用它证明。”

灰线骤然绷紧。

他掌心一疼，像裂痕被人往外拽开半寸。眼底旧针同时刺了一下，视野边缘泛起薄白。

林照的声音立刻切进来。

“呼吸。”

沈辞没有松手。

他把每个字压得很窄。

“源位灰痕，只作17号医疗远线后遗症记录。”

`可否作亲属参照`

“否。”

`可否作本人确认`

“否。”

`可否作改名依据`

“否。”

`可否作证件同步补项`

“否。”

杜衡同步删除四个框。

白线一截截断开，像被剪断的细发，落到总表边屏下方，转瞬被灰底吞掉。

顾焰的蓝点暗了下去。

他没有再劝，只在最后说了一句：“你是在拒绝一个很罕见的稳定机会。”

沈辞看着证背裂痕慢慢退回先前的颜色。

“那不是我的机会。”

屏幕退了一步。

`可保留同步影`

`不入证`

`不调用`

`仅作危急校验`

这一回，连杜衡的动作都慢了一拍。

危急校验。

如果下一次边界失控，保留影或许能救沈辞一命；如果知微那边突然恶化，保留影也可能提前预警。

它给出的不是权力。

是后路。

沈辞盯着那四个字，想起第113章黑箱替换模拟里，系统称知微为“可替换共鸣项”的瞬间。

那时它也不是立刻吞掉她。

它先给出一个看起来更安全的方案。

用影子替人，用参照替关系，用校验替回应。

他缓慢吐出一口气。

“同步影也不留。”

`危急状态可能无法回找源位`

“不回找。”

`候选人边界失控时可能缺少牵引`

“缺。”

林照那边的纸带停了一下。

这一次，她没有阻止他。

她只说：“记录他的拒绝，不记录她的灰痕。”

杜衡立刻补入。

`拒绝同步：沈辞本次限制判断`

`灰痕摘要：不录`

屏幕角落那点灰光终于从证面剥离出去。

远线那头，17号白床的灰光只剩很浅一层。

它没有消失。

也没有靠近。

屏幕压出结果。

`源位灰痕：不得同步入证`

`证件补项：不生成`

`亲属参照：否`

`本人确认：否`

`改名依据：否`

沈辞还没把临时证收回，裂痕下方忽然又浮出一圈极细的暗红。

不像同步。

更像警戒线。

新字贴着红线一点点显出来。

`改名边界`

`待预警`
