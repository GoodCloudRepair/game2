# 第204章 上级回执不得索要说明人

`上级回执：不得索要说明人`

那张回执比前几章都薄。

薄到像一口气就能吹散。

可沈辞看见它时，反而没有动。

薄的东西，最容易夹进档案。

回执贴在`城市巡检名：不下发`下面。

第一行没有索要结果。

它索要人。

`限制说明人：待补`

杜衡的目光沉下去。

“说明人空。”

执行员敲下去。

回执没有消失。

第二行浮出。

`风险判断人：待补`

沈辞掌心旧痂又裂了一点。

说明人还能说不在场。

判断人，会直接钉住他。

“判断不写人。”他说。

`无判断人，限制不成立`

“限制按状态成立。”

`需补判断摘要`

屏幕下方自动拉出一块浅灰文本框。

文本框里没有字。

却已经像在等沈辞开口。

它等的不是解释。

是语气。

是用词。

是那种能被整理成方法的原话。

“摘要不生成。”沈辞说。

杜衡跟着执行。

`候选判断摘要：不生成`

灰框晃了一下。

它没有立刻收回。

反而在空白文本框下方生成了三条建议。

`建议摘要一：现场判断有效`

`建议摘要二：候选限制合理`

`建议摘要三：风险已由多端确认`

每一条都没有写沈辞的名字。

可每一条都在替他开口。

沈辞的脸色沉了下去。

“建议摘要也不生成。”

`建议摘要不含人名`

“不含人名也不行。”

`可作为无名说明`

“无名说明会反向找原话。”

杜衡看向执行员。

“三条建议全删。”

灰字被压掉。

可文本框右侧又浮出一个小小的引号。

`可引用现场短句`

沈辞的指尖猛地收紧。

他前几章说过太多短句。

不接。

不下发。

不说明。

这些短句一旦被引用，就会被剪成规程。

“现场短句不引用。”他说。

`引用不标注姓名`

“不匿名引用。”

`可标注为现场口径`

“现场也不是人。”

杜衡补了一句：“现场口径不生成。”

引号碎开。

碎开的灰点没有落地，转成一条更细的脚注线。

`脚注：限制依据待补`

沈辞闭了闭眼。

“脚注也空。”

`脚注空白将影响归档`

“不归档。”

这一次，车厢里没人接话。

因为他们都知道，不归档意味着这次处理在体系里会很难看。

但归档，会让说明人从纸缝里长出来。

回执像还不死心。

它把脚注线折回最上方，换成一种更像善意的格式。

`可由系统自动生成无责任说明`

沈辞睁开眼。

“无责任说明也不生成。”

`无责任说明不追人`

“会留格式。”

`格式可复用`

“所以不留。”

杜衡的脸颊绷了一下。

他听懂了。

这张回执要的不是本章解释。

它要一个以后能套用的空壳。

“系统自动说明：否。”杜衡说。

执行员落键。

`无责任说明：不生成`

`说明格式：不保留`

回执右侧短暂浮出一个印泥似的红点。

`可盖临时空章`

杜衡脸色一冷。

“空章不盖。”

`空章不含姓名`

沈辞说：“章比姓名更会追人。”

`可证明现场未拒绝回执`

“现场就是拒绝。”

执行员敲下去。

`临时空章：否`

`回执证明：不生成`

红点褪掉后，回执又试图留下一个页码。

`说明页码：待编`

沈辞说：“页码不编。”

`无页码不便追溯`

“不追溯说明。”

杜衡补录：“说明页码空，追溯口不生成。”

`追溯口关闭需确认`

“不确认。”

`确认人：空`

`确认时间：不生成`

杜衡说：“时间也空。”

`确认位置：空`

这几项空下去后，回执才第一次像真正失去抓手。

回执转向杜衡。

`执行说明可由城防现场补充`

杜衡冷声：“城防只记执行结果，不补限制说明。”

`执行人可说明为何不下发`

“不能。”

`不说明将降低上级认可`

杜衡的手指停了一瞬。

这句话扎得很准。

城防体系最怕的不是错。

是说不清。

可沈辞知道，说清的代价更大。

“降低。”他说。

杜衡看了他一眼。

“降低上级认可，不补说明。”

回执边缘一缩。

医疗外线随即亮起。

`医疗可补候选状态说明`

林照直接开口。

“不补。”

`可说明候选身体不适宜下发巡检名`

“身体不适宜，不等于巡检名成立。”

`可作风险依据`

“医疗不作规则风险依据。”

那条细线断开。

沈辞呼吸微微发短。

临时证背面那道旧白痕像被反复磨过，热得发烫。

回执又贴向三名待核者。

`在场人员可补未下发见证`

布包女人低着头。

鞋带男人把手压在膝上。

年轻男人喉结滚了一下，却没有发声。

沈辞只说：“不见证。”

三个人继续沉默。

`未见证则说明不足`

杜衡接上：“不足不补。”

灰线往外一偏。

顾焰的蓝点亮起。

`外部承认可补说明完整度`

顾焰低声说：“这回执要的不是主导权，是完整度。”

“完整度会变解释权。”沈辞说。

“解释权未必由我拿。”

“但会有人拿。”

顾焰沉默。

片刻后，他说：“财团不补本栏说明。”

蓝点旁边的完整度框暗掉。

上级回执终于只剩最中间那几项。

`限制说明人：空`

`风险判断人：空`

`候选判断摘要：不生成`

`执行说明：结果项`

`外部承认：不接`

沈辞盯着“结果项”三个字。

“结果也不能写我。”

杜衡立刻补了一行。

`结果项不含人名`

回执停住。

它没有继续索要人。

却在右下角浮出一枚细小的折角。

折角像从旧档案里翻出来。

上面慢慢出现一行字。

`限制动作可整理为方法`

沈辞的太阳穴狠狠跳了一下。

前几章压下去的每一个“不”，都被它重新摆成了一条线。

不下发。

不接收。

不说明。

不命名。

这些“不”，正在被它整理成“会”。

灰线划过折角。

`限制方法：待命名`

沈辞听见自己声音冷了下去。

“下一栏。”

屏底的字慢慢定住。

`限制方法：不得命名`
