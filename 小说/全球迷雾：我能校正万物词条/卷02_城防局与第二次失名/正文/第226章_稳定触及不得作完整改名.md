# 第226章 稳定触及不得作完整改名

临时证右下角翘起的那一片，很薄。

薄得像旧证塑封老化后剥开的透明皮。

可沈辞一眼就知道，那不是自然裂损。

那片翘角正对着刚才退回裂痕深处的改名口。

总表边屏没有写“试开”。

它换了一个更稳的词。

`稳定触及`

`证面缺角待扣`

杜衡的声音沉下去。

“别碰。”

林照那边纸带已经开始记录。

`候选人左眼暗区扩大`

`指端温度下降`

`建议暂停接触`

沈辞没有立刻回答。

因为待核边线正在往内缩。

不是并格。

也不是清场。

三名待核者脚下的灰线像被同一口冷气推了一下，各自往内退了半寸，又在旧痕前停住。

临界读秒还停在`00:60?`。

问号却开始抖。

总表边屏顺势补字。

`稳定触及可终止临界波`

`仅触及边缘`

`不进入改名口`

`不作完整改名`

顾焰低声道：“它这次把退路都替你写好了。”

是。

它写得比任何人都谨慎。

不进入。

不完整。

不作改名。

只碰一下边。

像在说，只要沈辞愿意用证面缺角换一点稳定，所有人都能喘过这口气。

可沈辞看着那片翘起的证角，想起上一章旧名反扣时那圈浅勒痕。

半息不留存。

旧名不回写。

现在它只剩下触及。

总表边屏在“触及”两个字后面，悄悄展开一张预览页。

预览页上没有路线。

只有一条从证角到灰点的短线。

短线尽头挂着三个空框。

`接触`

`稳定`

`完成`

前两个框已经浅亮。

第三个框仍是空的。

空框没有亮，却一直贴着前两个框，像一节没挂上钩的车厢。只要前面两格被事实点亮，它不用再说服任何人，只需要让那节空车厢顺势撞上来。

沈辞盯着那张预览页。

“完成框删掉。”

`完成框未启用`

“未启用也删。”

杜衡照做。

那只空框被抹掉时，前两个框还在。

沈辞继续说：“稳定不接完成。”

杜衡又补。

`稳定触及不接完成项`

只要触及被写成完整改名的前一步，下一次就不需要问他进不进去。

它会说，他已经碰过。

沈辞开口：“触及不作步骤。”

`步骤不生成`

屏幕像早有准备。

`仅作本次临界止损`

林照说：“医疗不同意。”

`不同意将增加待核边风险`

杜衡盯着边线，脸色很难看。

人工封条的红灯一盏盏暗下去。

他可以删字。

但删不了封条疲劳。

沈辞看见杜衡按键的手停了一下。

那不是动摇。

是人力真的快到边了。
一条封条边缘已经翘起，旧胶被灰雾泡得发白，灯壳里有细小的噼啪声。杜衡的拇指按在删除键上，指甲下压出一圈血色，却迟迟没有落下第二次。

沈辞把临时证抬起来。

林照声音立刻拔高半分。

“沈辞。”

他没有看医疗外线。

“我不进。”

“它会把你写成进过。”

“所以只碰证角。”

顾焰冷声：“你以为系统分得清？”

沈辞说：“它分不清，我来分。”

他说完，把翘起的证角对准裂痕深处那粒灰点。

不是手指。

不是眼睛。

也不是名字。

只是一小片临时证面。

在他抬证的这几息里，三名待核者没有动。

可他们的旧痕都被那片证角牵了一下。

袖章下方浮出一道很淡的折线，布包口的旧线头竖起，鞋带结往内收紧。

像他们身体里最怕被写错的部分，都知道这一下可能换来短稳。

右侧人嘴唇动了动。

他没有出声。

沈辞看见了。

这比求救更难压。

如果有人求他，他还能拒绝那句话。可他们什么都没说，只是把活着的重量压在各自旧痕边上，像三件快被风掀走的旧物，等他决定要不要伸手按住。

沈辞把视线从他们身上收回来。

“不作请求。”

杜衡立刻把待核边线上的微光压掉。

`旧痕牵动：不作请求触及`

`待核者沉默：不作同意`

那片证面本来就是城防给他的监管借用物。

也是这一路所有限制、背注、裂痕和代价的承载物。

它可以损。

但不能替他进门。

证角碰上灰点的一瞬，沈辞耳边所有声音都断了一下。

总表边屏、医疗纸带、杜衡的键声、三名待核者压着呼吸的细响，全都像被塞进水里。

他看见几截极碎的字从灰点后浮出。

`换……`

`去名……`

`借……`

`不归……`

没有一截完整。

也没有一截能被他说出口。

灰点后面还有一块更白的空区。

空区像一页尚未打印的操作页。

页眉只露出半行。

`改名能力：`

后面空着。

空白比文字更危险。

因为只要沈辞多看一息，系统就能把他身体里的疼、证面的缺角、待核边的短稳一起填进去。

他闭了一下左眼。

只用右眼盯住证角和灰点相接的那一线。

“操作页不生成。”

杜衡声音紧得发硬。

`能力页：否`

林照补：“医疗体征不填能力页。”

顾焰也开口：“财团旁读不补空白能力项。”

沈辞立刻压住视线。

不读。

不补。

不替它们取名。

证角被灰点咬住。

一小片透明塑封无声碎开。

沈辞右手猛地一麻，麻意从指尖窜到腕骨，像有人把他的手从证面上临时擦掉了一拍。

林照那边纸带尖响。

`右手感觉缺失`

`证面损毁`

`可作完整改名触发证`

“否！”

林照这一声几乎和杜衡的删除键同时落下。

总表边屏红了一瞬。

`稳定触及已发生`

`完整改名可追认`

沈辞咬住舌尖，血腥味把那一拍空白压回现实。

“触及边缘。”

屏幕不动。

他重复：“只触及边缘。”

杜衡立刻拆行。

`触及位置：证面缺角`

`接触对象：改名口边缘`

`进入：否`

`完整改名：否`

顾焰补了一句。

“财团旁读不追认完整改名。”

沈辞没看他。

医疗纸带艰难退掉一行，又重新吐出。

`身体代价：本次触及后遗症`

`能力成熟证明：否`

证角终于从灰点上脱开。

那粒灰点没有扩大。

改名口也没有再亮。

待核边线退回各自旧痕外侧，封条红灯重新亮起三盏。

很少。

但够杜衡继续手动值守。

总表边屏冷冷落字。

`稳定触及：仅本次边缘`

`完整改名：否`

`能力页：不生成`

`后续步骤：不生成`

沈辞低头看临时证。

右下角缺了一小片。

缺口处露出灰白夹层，像证件被咬掉了一枚牙。

而证背的`辞`字底下，那点红少了一笔。

不是消失。

是少了一点属于他自己的回声。

总表边屏底部翻出下一行。

`代价回写`

`公共证明待生成`
