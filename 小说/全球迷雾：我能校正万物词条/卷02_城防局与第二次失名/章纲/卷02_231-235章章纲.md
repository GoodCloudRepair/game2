# 卷02_231-235章章纲

## 使用说明

- 对应卷：卷02 城防局与第二次失名
- 对应阶段：卷02卷尾收束 / 裂界列车预口
- 当前目标：承接第229-230章迁出预编和裂界列车预号，把外部迁徙压力写成预口、预检、候迁和随迁旧痕压力，不正式转场、不登车、不进入列车实景。
- 章内约束：仍停在安置区总表边屏、临时证、医疗外线、待核边线、城防值守端和财团旁读端；不进入城市外沿实景，不进裂界列车，不新增门域，不让沈辞稳定掌握完整改名，不让沈知微醒来或完整认亲。

## 段落总钩

- 起点：第228章末`迁出预编 / 本城旧名待核`浮出，外部迁徙压力开始贴近安置区总表。
- 预定落点：迁出预编、裂界列车预号、预检席、候迁栏和随迁旧痕都只能停在预口状态，不得生成迁出名、登车名、路线、出城口或完整迁徙名单。
- 后续方向：卷03可从外部候核压力接入裂界列车，但卷02末尾只留预号和候核灰灯，不正式登车。

## 第229章 已写：迁出预编不得改写海陵旧边

- 核心冲突：迁出预编试图用`海陵旧边 / 回头止处`、沈辞触及代价、知微共鸣升级和三名待核者旧痕生成本城迁出名。
- 关键新信息：迁出预编不得改写海陵旧边；旧边是封门止处，不是迁出名或离城名。
- 已落结果：迁出预编不得改写海陵旧边、回头止处、沈辞触及代价、17号白床共鸣或三名待核者旧痕为迁出名。
- 章末钩：`裂界列车预号：不得作登车名`。
- 禁触：不正式迁出，不生成路线，不写外部地图，不让旧边成为全城迁出凭据。

## 第230章 已写：裂界列车预号不得作登车名

- 核心冲突：裂界列车预号出现后，系统试图给沈辞、三名待核者、17号白床、城防值守端和财团旁读影号生成登车名。
- 关键新信息：裂界列车预号不得作登车名；预号只是外部压力提示，不是当前人员迁出证明。
- 已落结果：登车名、登车位、预批次、对象类型、预发时刻、路线和财团旁证均不生成。
- 章末钩：`预检席 / 临时证缺口待核`。
- 禁触：不登车、不写车厢、不写站台实景、不让知微上车、不让三名待核者整名确认。

## 第231章 已写：预检席不得接临时证缺口

- 核心冲突：预检席试图把沈辞临时证缺口、可信栏下调和外部承认缺失写成预检资格，诱导他以损证进入外部迁徙预检。
- 关键新信息：预检席不得接临时证缺口；缺口只作改名触及代价，不作迁出预检凭据。
- 已落结果：缺口不作预检资格、候选字校验、职业痕说明、回访对象或外部承认补口。
- 章末钩：`候迁栏 / 十七白床优先保护`。
- 禁触：不让沈辞成为预检对象、迁出代表、外部说明人或列车样本。

## 第232章 已写：候迁栏不得预留十七白床

- 核心冲突：候迁栏用共鸣阈值上移和优先保护名义，试图给17号白床预留候迁位。
- 关键新信息：候迁栏不得预留十七白床；医疗远线不作迁出优先项，未醒、未认回、未确认的对象不得被提前安排。
- 已落结果：优先保护位、同号床位借位、设备位、床旁备注、亲属候位和待醒保护均不生成。
- 章末钩：`随迁包 / 待核旧痕待合袋`。
- 禁触：不让知微醒来、上车、补证、作稳定项或被写入完整迁出名单。

## 第233章 已写：随迁旧痕不得合并出表

- 核心冲突：随迁包把三名待核者的袖章、布包、鞋带、纱布毛口和封条褶皱当成行李旧痕，试图合袋出表。
- 关键新信息：随迁旧痕不得合并出表；旧痕可证明边内活人仍在，不可变成随迁行李、合批名单或外部候核包。
- 已落结果：旧痕不合袋、不离边、不上传影、不拍保管照、不转编号影，遗失责任不生成。
- 章末钩：`外部候核灰灯 / 不照出城口`。
- 禁触：不确认三名待核者整名，不让旧痕离开待核边线，不生成出城口或车门。

## 第234章 已写：外部候核灰灯不得照成出城口

- 核心冲突：外部候核灰灯试图把预编、预号、预检和候迁结果照成出城口方向。
- 关键新信息：外部候核灰灯不得照成出城口；候核只证明外部压力存在，不证明可通行。
- 已落结果：候核灰灯只能照见外部压力存在，不生成方向、路线、出城口、门影或通行事实；外部承认缺失保留。
- 章末钩：`封缝回声 / 列车门影待核`。
- 禁触：不写出城实景，不展开列车站台，不让沈辞离开监测半径。

## 第235章 已写：封缝回声不得替列车开门

- 核心冲突：灰门监测缝回声被外部候核灰灯短接，试图替裂界列车开一条门影。
- 关键新信息：封缝回声不得替列车开门；监测缝是留缝封门后遗症，不是交通接口。
- 已落结果：监测缝只作封门后遗症，列车门影、开门依据、本地见证和门内回应均不生成；卷02外部迁徙预口封存。
- 章末钩：`裂界列车实核：待后续`，卷03正式迁徙压力承接。
- 禁触：不借监测缝当列车门，不让卷01灰门被重新打开，不提前进入卷03实景。
