# 卷02_121-130章章纲

## 使用说明

- 对应卷：卷02 城防局与第二次失名
- 对应阶段：阶段01 / 入档与编制失名
- 当前目标：承接第120章临时证和`编目师候选`，把HL-02落到现实管理体系。
- 章内约束：单章最多1个关键新信息；前五章不稳定改名、不揭编目庭、不让知微康复。

## 第121章 临时证不准过夜

- 章节功能：卷02开篇，正式把沈辞从封门幸存者写成被监管借用对象。
- 核心冲突：北库蓝鞋孩子刚被送到医疗点，沈辞想上前扶住倾斜的担架，临时证却先把他勒回入档黄线。
- 主要剧情：临时证正面完成`监管借用`登记，疲惫的入档员为清积压想手工补背面备注；蓝鞋孩子抵达时，沈辞越过黄线帮忙，证绳当场收紧，证背自行写出`不得离开监测半径`。杜衡只记录限制，并让紧急联系人继续留空。
- 关键信息：监测半径会直接限制沈辞的身体位置，来源和原点仍未公开。
- 章末钩子：评估传票落下：`封门余留活项 / 反读风险评估 / 立即入档`。

## 第122章 评估不测能力只测反读

- 章节功能：把城防局对沈辞的态度写成“需要但害怕”。
- 核心冲突：年轻技术员为了赶完评估误留总调度红线，沈辞一笔没改，三辆真实救援车已经被封门残边带偏。
- 主要剧情：空白档与封门残线在隔离柜中读出`来接人`；技术员误以为评估屏仍在练习模式，送氧车、伤员转运车和北库车同时收到错误路线。杜衡逐车截停，技术员承认失误，沈辞退出黄线后灰字才停止扩散。
- 关键信息：沈辞被判`不稳定变量`，能跟队，但不得直连总调度，任务必须人工下达并现场确认。
- 章末钩子：评估设备吐出残段：`HL-02`。

## 第128章 复核通道截走半页报告

### 定位

- 章节功能：财团线继续插入，把“复核通道已截取”从红字变成现场动作。
- POV：沈辞近景限知。

- 地点：海陵城防安置区三排十七床附近 / 临时归档桌 / 复核通道终端。
- 目标字数：2000-2200。

### 六问

- 推进哪一层主线：财团线与第二次失名线交叉，确认财团对HL-02有独立信息口。
- 核心冲突：城防局还没来得及把床位号异常归档，财团复核通道已经先截走半页报告。
