# 第128章：复核通道截走半页报告

## 1. 本章定位

- 所属卷：卷02 城防局与第二次失名
- 所属阶段：阶段01 / 安置区同名替换
- POV人物：沈辞（近景限知）
- 时间：D2 09:01-09:10，紧接三排十七床背面的红章
- 地点：三排十七床、临时归档桌、复核通道终端
- 章节功能：让财团线以一次具体的截页动作进入现场，确认信息口争夺已先于城防归档发生。

## 2. 本章目标（六问）

- 推进主线：财团线与第二次失名线交叉，并以父亲式旧标注触碰中层父亲线。
- 核心冲突：杜衡要封存三排十七床异常，复核通道却在封袋内把报告右半页抽走；沈辞不能让顾焰替城防放大、定义或补全残页。
- 局面变化：财团先拿到沈辞识名后留下的错名格空白，城防只保住左半页；信息不再只由现场掌握。
- 读者新认知：顾焰不进安置区也能借复核通道抢先看到材料，但他同样不能解释残页来源。
- 唯一关键信息：财团复核通道比城防本地归档更快。
- 章末钩子：原物资暂存门褪成`文修核验口`。

## 3. 剧情梳理

1. 杜衡下令封存床头牌，城防员刚把报告压进证物袋，袋内红线便把右半页连同错名格一并抽空。
2. 技术员拔掉外线仍无效，证明截取不走普通线缆；杜衡保住左半页，要求本地记录继续落档。
3. 顾焰以黑箱远端投出半页残影，想替现场放大并给材料编号。沈辞拒绝，防止财团把空格直接补成来源。
4. 林照从医疗点确认白床线暂稳，却要求沈辞别再追深。沈辞只读残页纸压，不读签名与来源，耳后旧伤再次出血。
5. 残页露出`截页后，勿补空格`的半句旧标注，顾焰也无法给出完整解释；右半页随即退回床头牌背面。
6. 安置区广播接入，原物资暂存门改显`文修核验口`。
