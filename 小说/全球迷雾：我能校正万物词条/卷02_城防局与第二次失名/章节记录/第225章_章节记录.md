# 第225章：旧名反扣不得写回沈辞

## 1. 本章定位

- 所属卷：卷02 城防局与第二次失名
- 所属阶段：阶段04 / 第二轮灾变与改名代价
- 章节功能：承接第224章`旧名反扣`，防止现用名被限制结果反向拼成稳定旧名
- POV人物：沈辞
- POV类型：第三人称贴近沈辞
- 时间：D3 01:10-01:20
- 本章开始时间：D3 01:10
- 本章结束时间：D3 01:20
- 时间跨度：约10分钟
- 与上一章间隔：无
- 地点：安置区总表边屏 / 临时证 / 待核边线 / 医疗外线 / 财团旁读端
- 目标字数：2000-2200字（可上浮至2300字，不能低于2000字）
- 实际字数：2110

## 2. 本章目标

- 本章要推进的主线层级：主角身份线与改名前置风险
- 本章核心冲突：总表试图用现用名、职业痕、协查残边、来接人旧痕和边线协助结果反扣成稳定旧名
- 这章结束后局面具体变化：旧名、代价、限制结果、职业痕和受益旁证不得互证成沈辞的稳定旧名
- 这章会让读者对谁产生新的认知：沈辞不是否认自己，而是拒绝被制度用结果拼成可调用的人
- 本章必须交代的信息：现用名如果被回写，会成为后续默认调用入口
- 本章新增物品/能力/规则/伏笔：新增规则`旧名反扣不得写回沈辞`
- 本章结尾钩子：`稳定触及 / 证面缺角待扣`
- 本章风格目标：用反向压痕、半名拆写、学校补名回扣和喉口卡名体现旧名危险
- 本章对应卷目标：逼近稳定触及前夜，但不让旧名替改名铺路

## 3. 本章剧情梳理

- 开场状态：第224章半息不留存后，临时证出现旧名反扣
- 事件一：总表试图把现用名`沈辞`写回，作为降低不稳定风险的稳定旧名
- 事件二：系统以职业痕、协查残边、来接人旧痕和边线协助结果拼出可制度化的沈辞
- 事件三：城防、医疗、财团和三名待核者都不作旧名确认或受益旁证
- 结尾结果：旧名反扣被压住，临时证右下角翘起，转入稳定触及代价
