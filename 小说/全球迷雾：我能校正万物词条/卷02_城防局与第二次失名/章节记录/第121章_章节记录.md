# 第121章：临时证不准过夜

## 1. 本章定位

- 所属卷：卷02 城防局与第二次失名
- 所属阶段：阶段01 / 入档与编制失名
- 章节功能：卷02开篇，把沈辞从封门幸存者正式写入城防局监管借用流程
- POV人物：沈辞
- POV类型：近距离限知
- 时间：D2 早晨
- 本章开始时间：D2 07:44
- 本章结束时间：D2 07:57
- 时间跨度：约13分钟
- 与上一章间隔：紧接第120章，临时证背面`编目师候选`未退
- 地点：临时医疗点外侧 / 城防局临时入档口 / 过夜复核岗
- 目标字数：2000-2200字（可上浮至2300字，不能低于2000字）
- 实际字数：2198字
## 2. 本章目标

- 本章要推进的主线层级：卷02官方体系线、主角身份线
- 本章核心冲突：北库蓝鞋孩子刚被送到医疗点，沈辞想上前帮住倾斜的担架，入档中的临时证却先把他勒回监测箱旁
- 这章结束后局面具体变化：蓝鞋孩子获救，沈辞的临时证通过正面入档，证背自行补出`不得离开监测半径`，他的行动自由当场受到限制
- 这章会让读者对谁产生新的认知：沈辞接受城防临时证不等于接受所有归档；杜衡只能记录和执行证背限制，无法替它确定来源与边界
- 本章必须交代的信息：限制在沈辞离开入档桌去扶担架时自行出现，没有任何人盖章或输入
- 本章新增物品/能力/规则/伏笔：临时证背面新增`不得离开监测半径`；评估传票：`封门余留活项 / 反读风险评估 / 立即入档`
- 本章结尾钩子：反读风险评估传票落下
- 本章风格目标：冷、被管、制度化，不写庆功
- 本章对应卷目标：建立“胜利后的不自由”，为HL-02体制内失名做前置

## 3. 本章剧情梳理

- 开场状态：入档员要求当天签发的临时证必须在入夜前归档，沈辞把证件交进读卡夹
- 事件一：临时证正面顺利入档，入档员为清掉积压队伍想跳过背面复核，候选字却卡住读卡夹
- 事件二：北库蓝鞋孩子被送到医疗点，担架轮陷进泥里；沈辞迈出黄线帮忙时，证绳突然勒紧，证背自行浮出`不得离开监测半径`
- 事件三：杜衡叫停强拉和补章，只记录限制；沈辞坚持紧急联系人留空，并让第120章的`17号白床不随证转移`继续有效
- 结尾结果：读卡夹自行吐出`封门余留活项 / 反读风险评估 / 立即入档`传票
