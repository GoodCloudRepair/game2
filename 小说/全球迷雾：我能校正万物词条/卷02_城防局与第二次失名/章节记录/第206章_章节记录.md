# 第206章：城防内栏同名不得下发

- 所属卷：卷02 城防局与第二次失名
- 所属阶段：阶段04开段 / 第二轮灾变与改名代价
- 章节功能：承接第205章`城防内栏：同名不得下发`，让第二次失名从上报链转入城防内部表格
- POV人物：沈辞
- POV类型：第三人称贴近沈辞
- 时间：D2 22:00-22:10

- 实际字数：2010

## 2. 本章目标

- 本章核心冲突：城防内栏试图把“同名”下发到城防、医疗、待核者和财团端口，并用短码、灰标、小窗、空值守位、页脚注记和已见标识绕过正式通知
- 本章关键新信息：第二轮失名开始从“外沿上报”转成“内栏同名”，不需要知道谁是谁，也能先把同名风险发给端口
- 本章结果：同名不下发，对象空，端口不接，同名提示否，同名队列不生成，内部待发否，短码空、灰标不显示、小窗不弹出，页脚空
- 本章结尾钩子：`内栏名单：不得替人认领`
